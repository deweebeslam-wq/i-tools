Sheet Organizer

Releasedi-Tools for Revit

Bulk rename, renumber, reorder and set discipline on sheets.

What it does

Sheet Organizer bulk-edits sheet numbers, sheet names, sheet order, and Project Browser folder grouping, all from one grid with a live "before → after" preview so you can see every change before committing.

Live-preview bulk rename (token pattern), renumber (start + step), reorder, and discipline grouping. Search/filter, client-side duplicate detection (Apply blocked on conflicts), single-undo writes, and a CSV audit log next to the .rvt. Modeless — stays open while you work.

When to use it

Renumbering a sheet set after a discipline reshuffle; applying a consistent naming pattern across dozens of sheets; reordering sheets in the sheet list to match the intended print sequence (renumbering to match); moving sheets between Project Browser folders (e.g. by discipline) without needing to touch Browser Organization settings in Revit itself; auditing/exporting a CSV log of every sheet renumbering for QA records.

How to open it

Click I-TOOLS tab → Utilities panel → "Sheet Organizer". Opens modeless — you can keep navigating sheets in Revit while it's open — and loads every ViewSheet in the model automatically.

Features

  • Toolbar
    • Search textbox — Filters sheets by number/name/discipline
    • Clear button — Clears the search textbox
    • Select All / Deselect All buttons — Ticks or unticks every visible sheet
    • Discipline filter dropdown — Shows only sheets of the picked discipline
    • Refresh button — Reloads sheets from the model
  • Mode
    • Rename radio button — Switches to token-based bulk rename mode
    • Renumber radio button — Switches to start+step bulk renumber mode
    • Reorder radio button — Switches to drag-order-based renumber mode
    • Grouping radio button — Switches to Project Browser folder grouping mode
  • Rename mode
    • Pattern textbox — Token-based rename template
    • Token buttons — Insert Discipline, SheetNumber, Name, Revision, or Index token
  • Renumber mode
    • Start textbox — First sheet number to assign
    • Step textbox — Increment between sheet numbers
  • Reorder mode
    • Move Up / Move Down buttons — Moves the selected sheet within the list order
  • Grouping mode
    • Grouping parameter dropdown — Chooses the shared/project parameter controlling Browser folders
    • Set value combo (editable) — Value to write onto checked sheets' grouping parameter
    • Move To button — Opens a folder picker to relocate checked sheets
    • Expand All / Collapse All buttons — Expands or collapses every folder node in the tree
    • Per-folder rename action — Rewrites a folder's grouping value on every sheet inside it
    • Per-folder new-subfolder action — Creates a subfolder under a folder for checked sheets
    • Per-folder delete action — Reports the folder's value-driven-folder limitation
    • Drag-and-drop sheets to folder — Moves a sheet into a different folder
  • Duplicate banner
    • Dismiss button — Hides the duplicate-number warning banner
  • Flat grid
    • Row checkbox — Includes/excludes a sheet from the pending operation
    • Status/conflict icon — Flags a row with a naming/number conflict
  • History
    • History expander — Collapsible list of past applied changes
  • Footer
    • Open Log button — Opens the CSV/log location
    • Undo Last button — Undoes the most recent applied change
    • Preview button — Force-refreshes the pending-change preview columns
    • Apply button — Commits all pending changes in one transaction
  • Onboarding
    • Got it button — Dismisses the first-launch welcome overlay
  • Move To dialog
    • Folder list — Lists existing Browser folders to move checked sheets into
    • New subfolder textbox — Names a new subfolder under the selected folder
    • Move / Cancel buttons — Confirms or cancels the folder move
