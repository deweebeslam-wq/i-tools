Parameters Add

Releasedi-Tools for Revit

Auto-calculate intelligent BIM parameters for structural columns.

What it does

Parameters Add automatically calculates and writes intelligent BIM parameters onto structural columns — which column sits above/below another, true top/bottom-of-column elevations, real geometric height, and nearest-grid location — plus a general-purpose card that copies a value from the room containing an element onto that element. Every calculation is preview-first and only writes to the model when you click Apply.

Four parameter cards: Column Relationship Detector (Column Above/Under + dead ends, linked models, slanted/transfer support), Column TOC & BOC (true geometric elevations in project/shared/internal coordinates), Column Height (real solid extent, never level maths) and Column Grid Location (nearest grid per direction family; radial/curved/rotated safe). Read-only preview, one undo step per card, CSV report, auto-created shared parameters with stable GUIDs (never duplicated).

When to use it

Populating "Column Above/Under" relationship fields for clash coordination; writing true TOC/BOC (top/bottom of column) elevations for shop drawings without hand-measuring; filling a Column Height parameter for quantity take-off; tagging columns with their nearest grid intersection (e.g. A-5) for schedules; copying a Room Number or Room Name onto light fixtures, diffusers, or any element that should "know" which room it's in.

How to open it

Click I-TOOLS tab → Utilities panel → "Parameters Add". Opens as a modeless, singleton window (2×2 card dashboard).

Features

  • Top bar
    • Discipline dropdown — User-chosen discipline that decides which cards are shown
    • Search parameter textbox — Filters visible cards by title or parameter name
    • Apply All Previewed button — Applies every active card that already has a preview built
  • Card 1 Relationship Detector
    • Active checkbox — Includes this card when Apply All Previewed runs
    • Linked models checkbox — Also considers columns in loaded Revit links as candidates
    • XY tolerance (mm) textbox — Horizontal matching tolerance between column ends
    • Z gap (mm) textbox — Vertical matching tolerance between a base and a top
    • Auto-create params checkbox — Creates the needed shared parameters automatically
    • Preview button — Computes Column Above/Under/dead-end values without writing
    • Apply button — Writes previewed values to the model
    • Cancel button — Stops a running preview
    • CSV button — Exports this card's last run
  • Card 2 TOC and BOC
    • Active checkbox — Includes this card when Apply All Previewed runs
    • Coordinates dropdown — Elevation datum: Match Levels, Internal, Project, or Shared
    • Unit dropdown — Display unit for elevations: mm/cm/m/ft
    • Snap to connected slab checkbox — Corrects for Join Geometry clipping the column at the slab face
    • Auto-create params checkbox — Creates the needed shared parameters automatically
    • Preview button — Computes TOC/BOC elevations without writing
    • Apply button — Writes previewed values to the model
    • Cancel button — Stops a running preview
    • CSV button — Exports this card's last run
  • Card 3 Column Height
    • Active checkbox — Includes this card when Apply All Previewed runs
    • Unit dropdown — Display unit for height: mm/cm/m/ft
    • Snap to connected slab checkbox — Corrects the height calculation for Join Geometry clipping
    • Auto-create params checkbox — Creates the needed shared parameter automatically
    • Preview button — Computes column heights without writing
    • Apply button — Writes previewed values to the model
    • Cancel button — Stops a running preview
    • CSV button — Exports this card's last run
  • Card 4 Grid Location
    • Active checkbox — Includes this card when Apply All Previewed runs
    • Search tolerance (mm) textbox — Max distance a column can be from a grid line and still match
    • Auto-create params checkbox — Creates the needed shared parameters automatically
    • Preview button — Computes nearest grid location without writing
    • Apply button — Writes previewed values to the model
    • Cancel button — Stops a running preview
    • CSV button — Exports this card's last run
  • Card 5 Room to Element
    • Active checkbox — Includes this card when Apply All Previewed runs
    • Scope dropdown — Current Selection, Active View, or Entire Model
    • Category dropdown — Narrows processing to one element category (or all room-aware ones)
    • Room parameter dropdown (source) — Room parameter whose value is read
    • Existing parameter radio + dropdown — Writes into an already-existing writable element parameter
    • New parameter radio + name/kind — Creates a brand-new shared parameter to write into
    • Refresh lists button — Re-scans the model for current room/element parameter names
    • Overwrite existing values checkbox — Controls whether non-blank destinations are replaced
    • Rooms from linked models checkbox — Also finds the containing room inside loaded links
    • Preview button — Computes room-to-element values without writing
    • Apply button — Writes previewed values to the model
    • Cancel button — Stops a running preview
    • CSV button — Exports this card's last run
  • Shared preview grid
    • Preview grid columns — Shows Element Id, Mark, Room, Target, Existing, up to 4 values, Status for the active card
