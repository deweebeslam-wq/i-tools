Join / Unjoin

Releasedi-Tools for Revit

Rule-based Join / Unjoin Geometry across the model.

What it does

Join / Unjoin lets you define rule-based, category-pair geometry operations (e.g. "Join every Floor to every Wall") and apply them across the whole model in one pass, instead of manually joining elements one pair at a time. It shows live counts of how many pairs intersect, are joined, not joined, or joined the "wrong way round" (inversely) for each rule.

Define category-pair rules (e.g. Floors ⇄ Walls). Live counts show intersections, not-joined, joined and joined-inversely per rule. Range: Project / Active view / Selection. Exclude temporarily-hidden or structural elements. OK applies all enabled rules in one undoable step.

When to use it

After importing/linking new geometry, after a structural design change that leaves floors/walls/columns unjoined, to batch-fix "can't keep elements joined" warnings, or to deliberately unjoin elements before an operation that Revit's join order would otherwise interfere with.

How to open it

Click Cleanup & QA → Join / Unjoin on the ribbon.

Features

  • Range panel
    • Range of operation — Chooses Project/Active view/Selection as the working set
    • Exclude temporarily hidden elements — Skips elements hidden in the view
    • Exclude all structural elements — Skips elements flagged structural
  • Rules grid
    • Is enabled — Turns one rule on/off (or all via header checkbox)
    • Operation — Chooses Join/Unjoin/Switch order for the rule
    • First category / Second category — Chooses the two categories the rule pairs
    • Swap (⇄) — Swaps First and Second category on a row
    • Delete rule (🗑) — Removes one rule row
    • Live stat columns — Shows Intersections/Not joined/Joined/Joined inversely per rule
  • Footer
    • Add new rule — Adds a blank rule row
    • Delete all rules — Removes every rule
    • Reset Settings — Deletes saved rules and preferences
    • Auto-calculate statistics — Recalculates counts live on every rule edit
    • Recalculate — Manually recomputes live counts
    • Apply — Runs every enabled rule and refreshes counts
    • Close / Help — Closes the window or shows help
