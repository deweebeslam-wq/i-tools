Element View Generator

Releasedi-Tools for Revit

Select element(s) in 3D → Top/Bottom/Left/Right/Front/Back/3D views, optionally on a sheet.

What it does

Element View Generator takes one element or a group of elements selected in a 3D view and produces a full set of orthogonal documentation views — Top, Bottom, Front, Back, Left, Right, and an isometric 3D — cropped tightly to the selection's own orientation (not the project's north), optionally placed and auto-centred on a new sheet. It's built for documenting individual pieces of equipment, connections, or assemblies, including ones rotated off the building grid.

Pick one element or a group in a 3D view and generate a complete documentation set. The combined ORIENTED bounding box drives every view, so a rotated beam or column gets views square to itself, not to the project axes (mixed orientations fall back to project axes and say so). Tick any combination of the seven views, choose Views Only or Views + Sheet, and the viewports are packed inside your title block in documentation order without overlapping. The 3D view gets a section box and an auto-fitted crop. A view template can be assigned to the section views and to the 3D view (separately — Revit templates are view-type specific); if a template owns the scale or the crop, the report says so. Names are predictable (EVG - Element 12345 - TOP); a second run on the same selection detects the existing views and offers Create New / Reuse / Ask. One Ctrl+Z undoes the whole run. Modeless — stays open while you work.

When to use it

Producing shop-drawing-style views of a single piece of equipment or a steel connection; documenting a rotated element (a beam on an angled grid, an off-axis column) with views square to the element itself instead of skewed project-axis crops; quickly generating a "detail sheet" for one selected assembly without manually creating six section views and a 3D view by hand; re-running the same documentation later and having the tool recognize and offer to reuse the views it made before.

How to open it

Click I-TOOLS tab → Utilities panel → "Element View Generator". Opens modeless; on open it automatically loads title blocks and adopts whatever is currently selected in Revit.

Features

  • Selection
    • Select Elements button — Starts an interactive pick of elements in the active 3D view
    • Use Current Selection button — Adopts whatever is currently selected in Revit
    • Clear button — Empties the current tool selection
    • Elements list — Shows each picked element, flagging any with no usable geometry
  • Views to create
    • View checkboxes — Tick any combination of Top, Bottom, Left, Right, Front, Back, 3D
    • All / None buttons — Ticks or clears every view checkbox at once
  • Output
    • Create Views Only radio — Generates views without placing them on a sheet
    • Create Views + Sheet radio — Generates views and places them on a new sheet
  • Sheet settings
    • Title Block dropdown — Chooses the title block family/type for the new sheet
    • Sheet Number textbox — Token-based sheet number pattern
  • View templates
    • Section Views dropdown — View template applied to the six orthogonal views
    • 3D View dropdown — View template applied to the isometric 3D view
  • Options
    • View Margin (mm) textbox — Padding around the selection inside each view's crop
    • Name Prefix textbox — Text prepended to every generated view name
    • Orientation dropdown — How the view frame is derived from the selection
    • If views exist dropdown — Policy for a re-run on the same selection: Create New, Reuse Existing, or Ask Me
    • View Scale Automatic checkbox — Lets the tool auto-pick a scale to fit the sheet
    • Fixed scale textbox — Manual view scale (1:N) when Automatic is off
    • Create Section Box checkbox — Adds a padded section box to the 3D view
    • Fit Views Automatically checkbox — Auto-crops/fits each view to the selection
    • Open the result when finished checkbox — Switches Revit to the new sheet/view after Create
  • Footer
    • CREATE button — Runs the view/sheet generation
    • CLOSE button — Closes the tool window
  • Duplicate dialog
    • Conflict list — Lists existing view names found for this selection
    • Cancel button — Aborts the current Create run
    • Create New button — Makes a fresh numbered set of views alongside existing ones
    • Reuse Existing button — Reuses the found views instead of creating duplicates
