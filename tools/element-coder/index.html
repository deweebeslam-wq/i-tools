Element Coder

Releasedi-Tools for Revit

Token-based bulk element coding with a conditional rule stack.

What it does

Element Coder writes a standardized coding value — built from a template like {ZONE}-{LEVEL}-{CAT}-{SEQ:3} — into any parameter you choose, across as many elements as you like, in a single pass. Conditional rules let different categories, levels, or families automatically get a different template, so one run can apply an entire office naming standard.

Write naming codes to any parameter using a {ZONE}-{LEVEL}-{CAT}-{SEQ:3} template. Type { for token IntelliSense. Conditional rules override the global template per category / level / parameter.

When to use it

Asset tagging and coding for FM/COBie handover, applying a company element-numbering standard to MEP equipment, doors, or rooms, generating unique short codes for schedules and tags, or re-coding elements after a scope or zone change.

How to open it

Click "Element Coder" on the I-TOOLS ribbon, Utilities panel. It opens a modeless window (you can keep working in Revit while it's open); a second click on the button re-activates the same window rather than opening a duplicate.

Features

  • Entry
    • Ribbon Button — Opens the modeless Element Coder window (singleton — reactivates if already open)
  • Run Tab
    • Preview Banner — Shows the live evaluated result of the current template against a sample element
    • Naming Template — Free-text template with {TOKEN} placeholders that gets written into the target parameter; typing { opens token IntelliSense
    • Zone / Prefix — Text field feeding the {ZONE} token used in templates
    • Write to Parameter — Dropdown choosing which Revit parameter receives the coded value
    • Reload Parameters Button — Re-scans the model to refresh the list of available parameter names
    • Also Write to Type — Mirrors the coded value onto the element's type parameter as well as the instance
    • Scope - Active View — Restricts coding to elements visible in the current view
    • Scope - Selection — Restricts coding to the elements currently selected in Revit
    • Skip Annotation Categories — Excludes annotation-category elements from the coding run
    • Overwrite Existing Values — Controls whether elements that already have a value in the target parameter get overwritten or left alone
    • Apply Green Colour Override — Applies a green graphic override in the view to elements successfully coded, as a visual confirmation
    • Run Coding Button — Executes the coding pass in one transaction
    • Results Panel — Shows a status summary and a per-element list of Written / Skipped / Error outcomes
  • Rules Tab
    • Add Rule Button — Creates a new conditional rule that can override the global template
    • Rule Name — Editable label identifying the rule
    • Rule Enabled Checkbox — Turns the rule on or off without deleting it
    • Rule Priority — Numeric order controlling which rule is checked first (lower number = higher priority)
    • Rule Template — Template that overrides the global template for elements this rule matches
    • Move Up / Move Down Buttons — Reorders a rule's priority relative to other rules
    • Delete Rule Button — Removes the rule entirely
    • Condition Field — Chooses what element attribute the condition checks (Category, CategoryCode, LevelName, LevelCode, FamilyName, TypeName, ParameterValue)
    • Condition Operator — Chooses the comparison (Equals, NotEquals, Contains, StartsWith, EndsWith — case-insensitive)
    • Condition Value — The text value the field is compared against
    • Condition Param Name — Names the parameter to read when Field = ParameterValue (disabled otherwise)
    • Remove Condition Button — Deletes a single condition from a rule
    • Add Condition Button — Adds another condition to a rule (all conditions AND together)
  • Config Tab
    • Level Rules Grid — Maps a keyword found in a level name to a short code used by the {LEVEL} token
    • Add/Remove Level Row — Adds or removes a row in the Level Rules grid
    • No Level (Empty) Code — Fallback code written for elements that have no level at all
    • Unknown Level Code — Fallback code when a level exists but no keyword rule matched it; blank auto-generates a 3-letter code from the level name
    • Category Rules Grid — Maps a category name to a short code used by the {CAT} token, with a search filter box
    • Add/Remove Category Row — Adds or removes a row in the Category Rules grid
    • Export Config Button — Exports the current configuration (templates, rules, code tables) to a file
    • Import Config Button — Loads a previously exported configuration file
    • Reset to Defaults Button — Restores the built-in default configuration
