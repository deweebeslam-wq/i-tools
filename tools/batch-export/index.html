Batch Export

Releasedi-Tools for Revit

Batch export sheets, views and schedules to PDF, DWG, NWC, Excel and more.

What it does

Batch Export lets you export many sheets, views, or schedules out of Revit in one operation instead of exporting them one at a time. You pick the sheets/views/schedules you want, tick the output formats you need (PDF, DWG, IFC, NWC/Navisworks, images, or Excel/CSV for schedules), and the tool runs through the whole list automatically, writing organized files to a folder you choose.

Sheets and Views export to PDF / DWG / IFC / NWC / images; the Schedules tab exports schedules to styled Excel (.xlsx) or CSV. Each category writes to its own sub-folder inside the export root.

When to use it

Issuing a full drawing set for a submission, producing coordination models (NWC) for a weekly clash meeting, generating IFC for a non-Revit consultant, batch-printing PDFs for a site set, dumping every schedule to Excel for a data handover, or re-running the exact same export (same sheets, same formats) week after week using a saved Sheet Set.

How to open it

Click the Batch Export button in the "Export Tools" panel on the I-TOOLS ribbon tab.

Features

  • Sheets Tab
    • Search box — Filters the sheet grid by number/name as you type
    • All button — Selects every currently visible sheet row
    • None button — Clears selection on every visible sheet row
    • PDF pill button — Enables the PDF format checkbox on every selected row at once
    • DWG pill button — Enables the DWG format checkbox on every selected row at once
    • IMG pill button — Enables the Image format checkbox on every selected row at once
    • Disable All button — Clears every format checkbox for the selected rows without changing row selection
    • Row select checkbox — Marks one sheet to be included in the export run
    • PDF/DWG/IMG per-row checkboxes — Chooses which formats to export for that one sheet
    • Export Name column — Overrides the output filename base for that sheet, editable inline
  • Views Tab
    • Search box — Filters the view grid by name/type as you type
    • All / None buttons — Selects or clears every currently visible view row
    • PDF/DWG/IFC/NWC/IMG pill buttons — Enables that one format for every currently selected view row
    • Disable All button — Clears every format checkbox for the selected view rows
    • Row select checkbox — Marks one view to be included in the export run
    • PDF/DWG/IFC/NWC/IMG per-row checkboxes — Chooses which formats to export for that one view
    • Export Name column — Overrides the output filename base for that view, editable inline
  • Schedules Tab
    • Search box — Filters the schedule list by name
    • All / None buttons — Selects or clears every visible schedule
    • EXCEL toggle pill — Writes a styled .xlsx workbook for the whole run
    • CSV toggle pill — Also writes a plain .csv file per schedule
    • Row select checkbox — Marks one schedule to be included in the export run
    • Output preview line — Shows a live preview of the resolved output filename pattern
  • Sheet Sets Bar
    • Sheet Sets dropdown — Picks a previously saved named selection of sheets/views plus their format checkboxes
    • Load button — Restores every checked item and its formats from the chosen saved set
    • Save button — Saves the current tick/format state as a new named set
    • Update button — Overwrites the selected saved set with the current state
    • Rename (✎) button — Renames the selected set or edits its description
    • Duplicate (⧉) button — Creates a copy of the selected set
    • Delete (🗑) button — Removes the selected saved set
  • Validation Bar
    • Live validation message — Explains why Export Now might be disabled
  • Footer
    • Root folder display — Shows the current export destination root folder
    • Close button — Closes the Batch Export window without exporting
    • Export Now button — Starts the export run for everything currently ticked
  • Export Progress Overlay
    • Current item/format display — Shows which sheet/view/schedule and format is exporting right now
    • Progress bar and stat grid — Shows Completed / Remaining / Elapsed / ETA / Speed
    • Cancel button — Stops the run after the current item finishes exporting
  • Settings – General
    • Export Folder field — Sets the root folder that all format sub-folders are created inside
    • Open Folder After Export toggle — Opens the export folder in Explorer once the run finishes
    • Show PDF Column toggle — Shows or hides the PDF checkbox column and pill in Sheets/Views grids
    • Show DWG Column toggle — Shows or hides the DWG checkbox column and pill in Sheets/Views grids
    • Show IFC Column toggle — Shows or hides the IFC checkbox column and pill on the Views grid only
    • Show NWC Column toggle — Shows or hides the NWC checkbox column and pill on the Views grid only
    • Show Image Column toggle — Shows or hides the Image checkbox column and pill in both grids
    • Show Schedules Tab toggle — Shows or hides the Schedules tab in the main window
    • PDF Folder Name field — Sets the sub-folder name created for PDF output under the export root
    • DWG Folder Name field — Sets the sub-folder name created for DWG output under the export root
    • IFC Folder Name field — Sets the sub-folder name created for IFC output under the export root
    • NWC Folder Name field — Sets the sub-folder name created for NWC output under the export root
    • Image Folder Name field — Sets the sub-folder name created for image output under the export root
    • Schedules Folder Name field — Sets the sub-folder name created for schedule output under the export root
    • Sheet Naming card — Token-pattern editor controlling exported sheet filenames, e.g. {Sheet Number} {Sheet Name} {Date} {Username}
    • View Naming card — Token-pattern editor controlling exported view filenames, e.g. {View Name} {View Type} {Date} {Username}
    • Schedule Naming card — Token-pattern editor for schedule filenames: {ScheduleName} {Category} {ProjectName} {ModelName} {Date} {Time} {Username}
    • Combined workbook name field — Sets the filename used when One Workbook Per Schedule is off
  • Settings – PDF
    • Combine Into One PDF toggle — Merges all selected sheets/views into a single PDF instead of one file each
    • Paper Size dropdown — Sets output paper size: Use Sheet Size / A4 / A3 / A2 / A1 / A0 / Letter / Legal / Tabloid 11x17
    • Orientation dropdown — Sets page orientation: Auto (match sheet) / Portrait / Landscape
    • Raster Quality dropdown — Sets image/raster rendering quality: Low / Medium / High / Presentation
    • Color Depth dropdown — Sets output color mode: Color / Grayscale / Black and White
    • Hide Reference Planes toggle — Hides reference planes in the exported PDF only
    • Hide Crop Boundaries toggle — Hides crop region boundaries in the exported PDF only
    • Hide Unreferenced View Tags toggle — Hides unreferenced view tags in the exported PDF only
  • Settings – DWG
    • DWG Export Setup dropdown — Picks a saved DWG export setup from the Revit project (File > Export > CAD Formats > DWG)
    • Refresh (↻) button — Re-reads DWG export setups from the project after new ones are created
    • DWG File Version dropdown — Sets AutoCAD compatibility version: 2018 / 2013 / 2010 / 2007 (manual settings only)
    • Layer Mapping dropdown — Sets how Revit categories map to CAD layers: AIA / ISO 13567 / CP83 (manual settings only)
    • Use Shared Coordinates toggle — Exports using the project's shared coordinate system instead of internal origin (manual settings only)
    • Export Views on Sheets as Links toggle — Exports each view on a sheet as a separate xref DWG file instead of merging them (manual settings only)
    • Export Rooms toggle — Includes Room elements in the DWG export (manual settings only)
    • Export Areas toggle — Includes Area elements in the DWG export (manual settings only)
  • Settings – IFC
    • IFC Version dropdown — Sets target IFC schema: IFC 2x3 (recommended) / IFC 4
    • Export Base Quantities toggle — Includes volume, area and length quantities in the IFC output
    • Export Revit Property Sets toggle — Includes Revit-specific parameter data as IFC property sets
    • Export Linked Files toggle — Includes geometry from loaded Revit links in the IFC export
    • Space Boundary Level dropdown — Sets geometric space boundary detail: None / 1st Level (2D) / 2nd Level (3D accurate)
  • Settings – NWC
    • Faceting Factor dropdown — Controls triangle mesh density: Low 0.25 / Normal 1.0 / High 2.0 / Maximum 5.0
    • Coordinate System dropdown — Sets NWC geometry origin: Internal Origin (default) / Shared Coordinates
    • Revit Parameters Export dropdown — Sets which parameter data is included: All Parameters / Element Parameters Only / None
    • Convert Element Properties toggle — Adds BIM parameter data as Navisworks object properties
    • Export Rooms as Attribute toggle — Includes room data as Navisworks properties
    • Export Linked Files toggle — Includes geometry from Revit links in the NWC export
    • Divide File Into Levels toggle — Organizes the NWC selection tree by building level
  • Settings – Image
    • File Format dropdown — Sets output image format: PNG / JPEG / TIFF / BMP
    • Resolution (DPI) dropdown — Sets print dots-per-inch: 72 / 150 / 300 / 600
    • Use Zoom Instead of Pixel Fit toggle — Switches between exporting at a fixed zoom % vs. fitting the view to a target pixel size
    • Fit Direction dropdown — Sets which edge the pixel count applies to (Fit mode): Horizontal / Vertical
    • Pixel Size dropdown — Sets target pixel count in the fit direction: 1024 / 2048 / 3840 / 5120 / 7680
    • Zoom % field — Sets the export zoom percentage (Zoom mode only)
  • Settings – Schedule
    • One Workbook Per Schedule toggle — Combines all selected schedules into one workbook (one worksheet each) when off
    • Overwrite Existing Files toggle — Auto-increments the filename instead of replacing an existing file when off
  • Settings Footer
    • Cancel button — Closes Settings without saving changes
    • Apply and Close button — Saves all settings changes and closes the dialog
  • Schedule Export - Exports Revit schedules (the same schedules you see in the Project Browser) to styled Excel workbooks or plain CSV files, so schedule data can be shared, edited, or archived outside Revit.
