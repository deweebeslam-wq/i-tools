Element Colorizer

Releasedi-Tools for Revit

Colour the active view by a parameter value, with optional hatch + legend.

What it does

Colors every element of a chosen category in the active view according to a parameter value you pick — for example, coloring all walls by their Type, or all pipes by their System — using temporary View Filters or per-element overrides, never permanent materials. Includes an optional hatch pattern as a second visual channel and a one-click legend.

Groups every element of a chosen category in the active view by a selected parameter (instance or type) and assigns a distinct colour per value. Apply as reversible View Filters (rule-based, shown in Visibility/Graphics) or per-element overrides. Optional drafting/model hatch as a second encoding layer for greyscale/colour-blind readability. One-click Legend builds a documentation view; Reset clears all overrides, purges the ITOOLS_Color_ filters and deletes the legend in one undo.

When to use it

- Producing a QA/coordination view colored by phase, level, system, or any other parameter. - Building color-coded drawings without manually creating View Filters by hand. - Producing a matching drafting-view legend for a sheet.

How to open it

I-TOOLS tab → Annotation pulldown → Element Colorizer. Opens as a modeless window.

Features

  • Source Panel
    • Category dropdown — Chooses which category to colour, limited to categories present in the active view
    • Group by dropdown — Chooses the parameter (instance or type) whose value drives the colour, icon-coded by filter capability
    • Method banner — States automatically whether View Filters or Element Overrides will be used and why
  • Options
    • Include blanks (none) — Also colours elements where the parameter is empty, under a (none) bucket
    • Hatch — Adds a second visual encoding (fill pattern) alongside colour
    • Model pattern — Uses a model fill pattern instead of a drafting pattern for the hatch
    • Hatch dropdown — Applies a chosen pattern to every value row at once
    • Numeric ranges — Groups numeric parameter values into equal-width bins instead of one colour per exact value
    • Bins textbox — Sets how many equal-width bins to use in numeric range mode
  • Values Grid
    • Colour swatch button — Opens the Windows colour picker to recolour a specific value
    • Per-row hatch dropdown — Overrides the hatch pattern for just this one value
    • Count column — Shows how many elements carry that value
  • Actions
    • Save button — Saves the current colour scheme to a .json file
    • Load button — Loads a previously saved colour scheme, matched back to values by label
    • Excel button — Exports the legend table (value/count/colour hex/hatch) to .xlsx
    • Refresh button — Re-scans the active view/category/parameter and rebuilds the values grid
    • Legend button — Creates or updates a drafting-view legend styled as a bordered SYMBOLS LEGEND table
    • Sheet button — Same as Legend but also places it on a new titleblock sheet
    • Reset current parameter — Clears colouring just for the currently chosen parameter in this view
    • Reset current category — Clears all colouring for the current category in this view
    • Reset this view — Clears everything Element Colorizer did in this view, including its legend
    • Reset EVERYTHING — Full cleanup of all views, legends, and legacy colouring across the project
    • Apply button — Colours the active view using the chosen mechanism (View Filters or per-element overrides)
