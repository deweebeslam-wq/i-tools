Clash Test Pro

Releasedi-Tools for Revit

Run native clash detection inside Revit — no Navisworks needed.

What it does

Clash Test Pro runs native clash detection directly inside Revit — no Navisworks round-trip required. You configure two element sets (Side A / Side B), a scope, and a tolerance, and it finds both hard clashes (solids physically intersecting) and soft clashes (clearance tighter than your tolerance), across host and linked models.

Pick two category sets, a scope and a tolerance; bounding-box broad phase + solid intersection narrow phase finds hard clashes, distance analysis finds soft clashes. Supports host and linked models, review workflow (status / assignee / comments) and Excel / CSV / HTML export.

When to use it

Quick in-Revit clash checks during design, MEP-to-structure clearance verification with a numeric tolerance, or coordination checks where spinning up Navisworks isn't worth it.

How to open it

I-TOOLS ribbon → "Coordination Tools" pulldown → Clash Test Pro.

Features

  • Side A/B card
    • Source radio (Host/Links/Selection) — Chooses where this side's elements come from
    • Category filter textbox — Filters the visible category checklist by typed text
    • All/None/Invert buttons — Bulk-select, deselect, or invert the visible category checkboxes
    • Expand/Collapse buttons — Expands or collapses all linked-model category groups (Links mode only)
    • Category checklist (Host mode) — Flat list of host-document categories to include on this side
    • Link groups (Links mode) — Per-linked-model expandable group with that link's own categories
    • Pick current selection button — Snapshots whatever is currently selected in Revit as this side's element set
    • Load saved Selection Filter set — Loads elements from a saved Revit Selection Filter (SelectionFilterElement)
    • Smart facet filters (Family/Type/Level/Workset/System) — Narrows a Selection-mode snapshot in-memory by facet
  • Comparison strip
    • Estimate button — Runs collection + broad phase only to preview element/pair counts and a processing-time range without full detection
  • Options card - Scope
    • Entire project/Active view/Workset/Phase radios — Limits which host elements are scanned (links unaffected by Workset/Phase)
  • Options card - Detection
    • Hard clash checkbox — Enables detection of solid-to-solid intersections
    • Soft clash checkbox + Tolerance textbox — Enables clearance-based detection: flags pairs closer than the tolerance without touching
  • Options card - Ignore
    • Joined/Same type/Same MEP system/Same group instance checkboxes — Excludes clash pairs matching these conditions from results
  • Run bar
    • RUN CLASH TEST button — Starts detection using current Side A/B and options
    • Cancel button — Stops a running detection
    • Reset button — Clears all detected clashes, filters, and cached results without touching the model
  • Results toolbar
    • Filters toggle — Shows/hides the facet filter panel (Category A/B, Level, Workset)
    • Free-text search box — Instant search across element ID, category, level, grid, workset, assignee, comment, status
  • Facet filter panel
    • Category A/Category B/Level/Workset dropdowns — Narrows the results grid to clashes matching these facets
    • Clear button — Resets all facet filters and the search box
  • Status stat cards
    • New/Active/Reviewed/Approved/Resolved cards — Shows count and % per status; click filters the grid to that status
    • Show all button — Clears an active status filter
  • Results grid
    • Status dropdown (per row) — Sets the clash's review status
    • Assignee/Comment columns — Editable text fields for who is responsible and notes
    • Actions column — Per-row zoom/section/isolate/copy info buttons
  • Keyboard shortcuts
    • Ctrl+I/Ctrl+S/Esc — Isolate/Section/Return-to-previous-view shortcuts for the selected clash
  • Footer
    • Export CSV/Excel/HTML buttons — Exports the current filtered results grid to file
    • Return to view button — Restores the view state from before navigation
