Smart Repeat

Releasedi-Tools for Revit

Repeat element(s) along a path with tangent alignment (cable trays, ducts, pipes, lines).

What it does

Smart Repeat copies one or more selected elements along a path — a line, duct, pipe, cable tray, conduit, arc, spline, or any mix of these chained together — automatically rotating each copy to follow the path's true 3D tangent. It's built for repetitive placement tasks like hangers, supports, or fixtures along a run.

When to use it

Placing supports/hangers evenly along a duct or pipe run, repeating a light fixture or sensor along a corridor, distributing furniture or equipment along a curved or sloped path, or copying a family along any chain of connected lines/MEP segments without manually rotating each copy.

How to open it

Click Modeling Tools → Smart Repeat on the ribbon.

Features

  • Selection
    • Pick Element(s) — Picks the source element(s) to repeat
    • Pick Path — Picks the seed path element(s)
    • Follow — Chooses how far the path auto-expands from the picked seed
    • On branch — Chooses how a forked path is resolved
  • Distribution
    • Mode — Chooses By Spacing/By Quantity/Fill Path
    • Spacing (mm) — Sets the distance between stations
    • Qty — Sets the number of stations for By Quantity mode
    • Start off / End off (mm) — Trims usable path length from each end
    • Rot° offset — Extra rotation applied after tangent alignment
    • Align with path — Orients each copy's facing to the path's 3D tangent
    • Include first / Include last / Skip last — Controls whether end stations are placed
  • Preview
    • Update Preview — Computes and displays the station list and length readout
    • Preview list — Shows index/element/location for first 20 stations
    • Debug panel — Shows diagnostic counters and reason Apply is enabled/disabled
  • Footer
    • Apply — Places copies at every computed station
