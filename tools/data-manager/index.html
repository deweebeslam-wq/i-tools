Data Manager

Releasedi-Tools for Revit

One window for schedules ↔ Excel, the Parameter Editor, shared parameters and parameter audit.

What it does

Data Manager is a single window that covers four related data workflows: pushing Revit schedules out to Excel, pulling edited Excel data back into the model, batch-editing parameters across many elements at once, and administering shared parameters plus running QA audits on parameter values. It is the successor to the older Schedule↔Excel exchange tool, expanded into a full data hub.

When to use it

Sending schedule data to a consultant for markup and reimporting their edits; renaming/reformatting a parameter value (e.g. converting a Mark to uppercase) across thousands of elements in one pass; creating and binding a new shared parameter to categories without leaving Revit; or running a QA sweep to find elements missing a required parameter value.

How to open it

Click the Data Manager button in the "Data Tools" panel. The window is modeless, so you can keep it open and still click/select in the Revit canvas.

Features

  • Title Bar
    • Refresh Schedules button — Re-reads the current list of schedules from the model
  • Export Tab
    • Schedule list — Lists every schedule in the project for export
    • Export all checkbox — Exports every schedule instead of just the selected one
    • Output File field + Browse — Sets the destination Excel file path
    • Export to Excel button — Writes the schedule(s) to a styled Excel workbook
  • Import & Apply Tab
    • Excel Source File field + Browse — Sets the edited Excel file to import from
    • Detect Changes button — Compares the Excel file against the live model and lists every changed cell
    • Select All / Deselect All buttons — Ticks or clears every row in the Changes grid
    • Changes grid row checkbox — Marks one detected change to be written back to the model
    • Apply Selected Changes button — Writes every ticked change to the model in one transaction
  • Parameters Tab
    • Scope dropdown — Sets which elements are candidates: Current selection / Active view / Whole model
    • Collect Elements button — Gathers elements from the model matching the chosen scope
    • Categories checklist — Restricts the working set to ticked categories
    • Parameters search box — Filters the parameter checklist by name
    • Parameters all/none buttons — Ticks or clears every parameter in the list
    • Parameters checklist — Chooses which parameters become grid columns
    • Build Grid button — Builds the editable data grid from the collected elements and ticked parameters
    • Operation dropdown — Chooses the batch action to run, e.g. Set Value / Find and Replace / Copy Param to Param / Pattern Builder / Prefix / Suffix / Convert Case
    • Target parameter dropdown — Chooses the parameter column the batch operation writes to
    • Find & Replace inputs — Text to search for plus a case-sensitivity toggle
    • Value/Replace/Pattern box — Free-text value used by Set Value, Replace, or Pattern Builder operations
    • Pattern Builder token popup — Suggests grid columns and Category/Id/Name as insertable tokens while typing a pattern
    • Copy from dropdown — Chooses the source parameter for the Copy Param to Param operation
    • Convert Case dropdown — Chooses a text case transform: UPPERCASE / lowercase / Title Case / Sentence case / PascalCase / camelCase / snake_case / SCREAMING_SNAKE / kebab-case
    • Prefix field — Text added before every value
    • Suffix field — Text added after every value
    • Selected rows only checkbox — Restricts the batch operation to only the rows currently selected in the grid
    • Stage button — Applies the batch operation to the grid only, without writing to Revit
    • Add Condition button — Adds a row filter that gates the batch operation
    • Filter Clear button — Removes all condition filters
    • ALL(AND) / ANY(OR) radio buttons — Chooses how multiple filter rows combine
    • Parameter grid — The main editable table of elements x parameters
    • Conditional Rules Add/Duplicate/Delete buttons — Adds, copies, or removes an IF/THEN rule row
    • Conditional Rules move up/down buttons — Reorders a rule since rules run top to bottom
    • Conditional Rules Import/Export buttons — Loads or saves the rule set to a file
    • Rule row: On checkbox — Enables or disables one conditional rule without deleting it
    • Rule row: IF Parameter, Operator, Value — Defines the rule's condition
    • Rule row: THEN Action, Action Value, Replace — Defines what the rule does when its condition matches
    • Shared Params button — Opens the Shared Parameter Admin dialog
    • Audit button — Opens the Parameter Audit dialog
    • Excel export button — Exports the current grid to Excel, including ElementID/UniqueID for re-import matching
    • Excel import button — Imports an edited Excel file and stages the differences into the grid
    • Revert button — Discards all staged changes in the grid
    • Preview button — Shows a text preview of exactly what Apply would write
    • Apply to Revit button — Writes every staged change to the model in one transaction
  • Status Bar
    • Open Log button — Opens the plain-text log file for this session
  • Shared Parameter Admin
    • Browse shared file button — Selects the active shared parameter file
    • Refresh button — Re-reads definitions and bindings from the shared file and project
    • Definitions search box — Filters the shared-file definitions list
    • New Definition fields — Name, Group, Data Type inputs for creating a new shared parameter definition
    • Create button — Creates the new parameter definition in the shared file
    • Bound in this project list — Shows every shared parameter currently bound to the project
    • Unbind Selected button — Removes the selected parameter's project binding, keeping the shared-file definition
    • Category search + All/None — Filters and bulk-selects categories to bind the definition to
    • Category checklist — Chooses which categories the definition binds to
    • Instance / Type radio buttons — Chooses whether the parameter binds as an instance or type parameter
    • Group Under dropdown — Chooses the parameter group the binding appears under in Revit's UI
    • Bind to Categories button — Creates the project binding for the selected definition and categories
    • Export List button — Exports shared-file definitions and project bindings to a two-sheet Excel file
    • Export Preset button — Saves every shared parameter bound in this project as a JSON company preset
    • Apply Preset button — Creates missing definitions and binds every preset item to its categories
  • Parameter Audit – Health Dashboard
    • Scan Health button — Runs the built-in health checks over the model
    • Export button — Exports the health scan results
    • Issue-type filter chips — Filters the issues grid to one issue type, or shows all
    • Issues grid — Lists every detected health issue with severity, parameter, detail, category and element id
  • Parameter Audit – Custom Rules
    • Add Rule button — Adds a new blank QA rule row
    • Save Set / Load Set buttons — Saves the current rule set to a file, or loads a saved one
    • Rule row: Category, Parameter, Rule type, Pattern, Severity — Defines one QA rule, e.g. required value, regex naming, value list, or numeric range
    • Remove rule (✕) button — Deletes one rule row
    • Run Audit button — Runs every enabled rule over the whole model, read-only
    • Export Report button — Exports the violations list to a file
    • Violations grid — Lists every rule violation with severity, category, element, parameter, actual vs expected value
