Smart Sectioner

Releasedi-Tools for Revit

Search for an element and generate a precision section box around it.

What it does

Smart Sectioner lets you search for any element by its Revit Element ID — in the host model or in any loaded linked model — and instantly build a 3D section box zoomed around it. It replaces the manual work of hunting an element down and setting up a section view just to look at it.

When to use it

You have an element ID from a clash report, warning dialog, schedule, or RFI and need to see it in context fast; you want a quick isolated/highlighted 3D screenshot of one element for a markup or email.

How to open it

Click the I-TOOLS ribbon tab → "Coordination Tools" pulldown → Smart Sectioner.

Features

  • Search tab
    • Element ID box — Text field to type a Revit Element ID (integer)
    • Search button — Runs element lookup and generates the section box
    • Result info card — Displays the found element's name and source (host or link name) after a successful search
    • Copy View to Clipboard button — Captures the active 3D view and copies it to the Windows clipboard
  • Section Box Settings
    • Box Offset slider — Sets the margin (10-5000mm) added around the element bounding box for the section box
    • Isolate element in view checkbox — Temporarily isolates only the found element in the 3D view
    • Highlight element (red override) checkbox — Applies a red graphic override (line + solid fill) to the found element
  • History tab
    • Entries list — Lists past searches with title/subtitle and count badge
    • Re-apply button — Reruns a past search with its saved Element ID and offset
    • Delete button — Removes a single history entry
    • Clear All button — Deletes all history entries
  • About tab
    • Features list — Static reference list of the tool's capabilities
