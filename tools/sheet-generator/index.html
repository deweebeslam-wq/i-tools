Sheet Generator

Releasedi-Tools for Revit

Create, plan, import / export and manage sheets: manual creator, rules per level, planner, Excel round-trip, existing-sheet manager.

What it does

Sheet Generator automates the repetitive "one plan view + one sheet per level" workflow: pick levels and a small set of plan rules (Floor / Structural / Ceiling plan, each with its own view template, scale, and optional scope box), and it creates every plan view, a sheet for each, and a centred, auto-fitted viewport on your chosen title block — all in one batch. A Planner tab lets you freely rearrange the resulting plan (drag views between sheets, add extra sheets, reuse or duplicate existing views) before you actually generate anything in the model.

One window for the whole sheet set. Sheet Creator: type or paste numbers and names, pick title blocks and views, batch-add with auto-numbering. Auto Generator: every level → plan views → sheets, named by token patterns with a live preview. Planner: drag views between sheets with undo / redo and a layout preview. Excel Manager: export sheets, parameters and view assignments, edit in Excel, import back with column mapping, validation, conflict detection and a preview before anything changes. Existing Sheets: rename / renumber, edit parameters, change title blocks, duplicate, find empty sheets and numbering gaps. Every operation is one Ctrl+Z. Modeless — stays open while you work.

When to use it

Standing up a full set of floor/structural/ceiling plan sheets at the start of a project or after adding several new levels; regenerating a consistent sheet set after level restructuring; building a documentation set that also needs to reuse or duplicate specific existing views (e.g. onto new sheets) alongside the newly generated ones; laying out a bespoke sheet-to-view arrangement by hand using the Planner before committing.

How to open it

Click I-TOOLS tab → Utilities panel → "Sheet Generator". Opens modeless with two tabs: Setup (rule-based) and Planner (free-form editable plan with undo/redo).

Features

  • Setup - Levels
    • Levels checklist — Ticks which levels are processed by the plan rules
    • All / None buttons — Ticks or clears every level at once
  • Setup - Plan rules
    • Kind dropdown — Floor Plan, Structural Plan, or Ceiling Plan
    • View type dropdown — Specific View Family Type used for the created view
    • Template dropdown — View template applied to created views
    • Scale textbox — View scale denominator (1:N)
    • Scope box dropdown — Optional scope box to crop the view
    • View name pattern textbox — Token-based naming for created views
    • Remove rule button — Deletes a rule row
    • Add rule button — Adds a new empty rule row
  • Setup - Sheet options
    • Create sheets checkbox — Controls whether sheets are generated alongside views
    • Group dropdown — One sheet per level (multi-view) or one sheet per view
    • Title block dropdown — Title block family/type for generated sheets
    • Number pattern textbox — Token-based sheet number pattern
    • Sheet name pattern textbox — Token-based sheet name pattern
    • Margin mm textbox — Content margin inside the title block's printable region
    • Title strip mm textbox — Height reserved for the title block strip
    • Auto-fit scale checkbox — Lets the tool coarsen a view's scale to fit its viewport cell
    • Existing views button — Opens the Existing Views picker to add reuse/duplicate jobs
    • Existing job remove button — Removes an added existing-view job from the batch
  • Setup - Preview
    • Dry-run preview grid — Shows exactly what Generate would create without changing the model
  • Planner
    • Build plan button — Populates the plan from Setup rules and existing-view jobs
    • Undo / Redo buttons — Steps backward/forward through Planner edits
    • New sheet button — Adds an empty sheet to the plan by hand
    • Generate plan button — Commits the current Planner plan to the model
  • Planner - Properties
    • Sheet number/name textboxes — Edits the selected sheet's number and name
    • View name/Scale/Template/Scope box — Edits the selected (new) view's properties
  • Planner - Sheets column
    • Sheets list — Lists every planned sheet; drag a view onto one to place it
  • Planner - Views on sheet column
    • Views on sheet list — Views currently placed on the selected sheet
  • Planner - Unassigned column
    • Unassigned pool list — Views not yet placed on any sheet
  • Planner - Preview
    • Sheet preview canvas — Rough visual layout of the selected sheet's viewports
  • Footer
    • Preview button — Refreshes the Setup dry-run preview grid
    • Generate (rules) button — Runs the rule-based batch directly from Setup
  • Existing Views dialog
    • Search textbox — Filters the views list by name/type/level/scale/sheet
    • Views list (grouped multi-select) — Lists project views grouped by type for picking
    • Action dropdown — Reuse existing, Duplicate, Duplicate with detailing, or Duplicate as dependent
    • Copies textbox — Number of duplicate copies to create
    • Name pattern textbox — Token-based naming for duplicated views
    • Add to plan / Cancel buttons — Confirms or cancels adding the selected views as jobs
