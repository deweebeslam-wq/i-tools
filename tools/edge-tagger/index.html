Edge Tagger

Releasedi-Tools for Revit

Place a face-based annotation family on the edges of selected structural elements.

What it does

Places a small face-based annotation family (a dot marker by default) at the corner points of the top face of structural elements, so every corner of a column, footing, floor edge, or wall can carry a marker or callout. Useful for edge-condition callouts, punch-list markers, or QA dot-marking.

Select columns / floors / footings / walls in a 2D plan view. EdgeTagger finds each element's top face and places the bundled face-based family on its edges. Modes: all edges, interactively-picked edges, longest edge, or the N longest edges. Options for inner-loop edges, shared-edge dedup, inward offset and linked-model elements. The family auto-loads from the bundled "THE DOT" family (or browse to your own .rfa).

When to use it

- Marking every corner of foundation footings for a survey set-out sheet. - Flagging slab edge corners for waterproofing or edge-condition details. - Placing markers only on specific longest edges of columns for elevation callouts.

How to open it

I-TOOLS tab → Annotation pulldown → Edge Tagger, while a 2D plan view (Floor Plan or Structural Plan) is active — 3D views are rejected.

Features

  • Selection
    • Pre-selection — Uses elements already selected in the model instead of prompting to pick
    • Interactive pick — Prompts to pick structural elements when nothing is pre-selected
  • Options Dialog
    • Placement Mode - All corners — Tags every corner of every selected element's top face
    • Placement Mode - Selected corners — Lets you pick individual edges interactively; nearest corners of each picked edge are tagged
    • Placement Mode - Longest edge — Tags only the two corners of each element's single longest top-face edge
    • Placement Mode - N longest edges — Tags corners of the N longest edges per element, N set via textbox
    • Include inner-loop edges — Also tags corners of interior openings/voids in the top face, not just the outer perimeter
    • Skip duplicate midpoints on shared boundaries — De-duplicates corner points shared by two adjacent elements so markers do not overlap
    • Include elements from linked Revit models — Also tags elements picked from loaded/linked Revit models, not just the host model
    • Inward offset from edge (ft) — Nudges the placed marker inward from the exact corner point by this distance
    • Preview text — Shows how many corners were found across how many elements before placing
    • Cancel button — Closes the dialog without placing anything
    • Place button — Confirms options and starts placement
  • Placement Robustness
    • Face-hosted placement — Primary placement method using the element's real face reference
    • Ray-cast recovery — Shoots a vertical ray to recover a valid face reference when the element's own geometry reference is null (e.g. joined/cut beams)
    • SketchPlane fallback — Last-resort placement using a constructed sketch plane when no face reference is available
  • Family Loading
    • Auto-load bundled family — Loads THE DOT family automatically the first time the tool runs
    • Browse fallback — Prompts to browse for a compatible .rfa if the bundled family fails to load (e.g. saved in a newer Revit version)
  • Result
    • Summary TaskDialog — Reports placed / duplicate-skipped / failed counts after running
