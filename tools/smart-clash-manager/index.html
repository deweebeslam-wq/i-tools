Smart Clash Manager

Releasedi-Tools for Revit

Import Navisworks clash XML — review, isolate, section, comment.

What it does

Smart Clash Manager imports a Navisworks Clash Detective XML export directly into Revit, so your team can review, section, isolate, and track the resolution of every clash without needing Navisworks installed. Each clash keeps a persistent status, assignee, and comment thread that is saved into the Revit model.

Per-row 🔍 zoom button applies a smart section box around each clash (no temp isolate). Ctrl+S creates a context Section view automatically. Workflow state (status / assignee / comments) is persisted per document.

When to use it

After running clash detection in Navisworks and exporting the results, to walk through clashes with the design team inside Revit, assign owners, and document resolution progress.

How to open it

I-TOOLS ribbon → "Coordination Tools" pulldown → Smart Clash Manager.

Features

  • Toolbar
    • Import XML button — Opens a file browser to import a Navisworks Clash Detective XML export
    • Refresh Cache button — Clears the resolver and image caches and reloads the current preview image
    • Save Workflow button — Persists all status/assignee/comment changes to the Revit model
    • Debug toggle — Toggles visible TaskDialog checkpoints for troubleshooting (logging always happens)
    • Diag button — Dumps full diagnostics to the log file and shows a summary dialog
    • Mode dropdown — Chooses how the section box is centered: clash point vs union of both element bounding boxes
    • Size dropdown — Sets the section-box radius/zoom margin: 250/500/1000/2000mm
    • Search box — Free-text filter across clash fields
  • Status chips
    • New/Active/Reviewed/Approved/Resolved chips — Shows count per status; clicking filters the grid to that status
    • Clear filter button — Removes any active status filter
  • Clash grid
    • Zoom button (per row) — Selects the row and navigates Revit to that clash with section box/isolation applied
    • Status column — Colored badge showing clash workflow status
    • Assignee column — Editable text field for who is assigned to resolve the clash
    • Comment column — Editable free-text note per clash
  • Preview pane
    • Clash Viewpoint image — Shows the clash photo embedded/referenced in the Navisworks XML
    • Activity comment thread — Shows dated history of status changes and notes for the selected clash
    • Add comment textbox + Add button — Adds a free-text note to the selected clash's activity history
  • Footer
    • Isolate button (Ctrl+I) — Temporarily hides everything except the two clashing elements in the active view
    • Return button — Restores the view and section box state from before navigation
    • Section button (Ctrl+S) — Creates or activates a section view centered on the selected clash
    • Active/Approved/Resolved buttons — Sets the selected clash's workflow status
