Element ID Picker

Releasedi-Tools for Revit

Pick element(s) from the host model or any linked Revit model and copy their real Element IDs.

What it does

Element ID Picker lets you click on elements inside a loaded linked Revit model and instantly get their real, permanent Element IDs — the ID that belongs to the element inside its own source file, not the ID of the link instance that Revit shows you by default. It is a read-only lookup tool: nothing in your model or the link is ever changed.

For elements inside a linked model the plugin resolves Reference.LinkedElementId via RevitLinkInstance.GetLinkDocument() so the ID shown is the REAL element ID — never the host link-instance ID.

When to use it

When you need to reference a specific element inside a consultant's linked model — for a coordination email, an issue report, a Dynamo/API script, or a BIM execution plan note — and a normal click in Revit only gives you the meaningless link-instance ID rather than the element's true ID inside its own file.

How to open it

Click the "Element ID Picker" button on the I-TOOLS ribbon tab, Utilities panel. Picking starts immediately — there is no separate window to configure first.

Features

  • Entry
    • Ribbon Button — Opens the picker and immediately starts a pick session
    • Link Requirement Check — Refuses to run if no Revit link is loaded in the model
  • Picking
    • Pick Elements — Lets you click one or more elements inside any loaded linked model (host elements are not pickable)
  • Results Table
    • # Column — Shows the row index in click order
    • Element ID Column — Shows the real element ID inside the link's own document, not the link-instance ID
    • Link Instance Column — Shows which loaded linked file the element came from
    • Category Column — Shows the linked element's Revit category
    • Copy ID Button — Copies just that row's element ID to the clipboard
    • Copy Name Button — Copies that row's link instance name to the clipboard
    • Error Row — Shows an inline error message instead of ID/category when a pick could not be resolved (e.g. link unloaded)
  • Warnings
    • Warnings Panel — Collapsible amber banner listing every row that failed to resolve, with row number and reason
  • Footer
    • Copy All IDs Button — Copies every successfully resolved element ID to the clipboard, one per line
    • Close Button — Dismisses the results window
