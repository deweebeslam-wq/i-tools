i-CLASH REPORT PRO

Releasedi-Navis

Turns Clash Detective results into a client-ready PDF report, an interactive HTML dashboard and, optionally, the Navisworks-format XML and tabular HTML. You control exactly which clashes go in, filtering down to a single parameter value such as Zone 3.

How to open it

Click i-CLASH REPORT PRO in the Clash Reporting on the i-TOOLS ribbon tab in Navisworks.

Features

  • Clash source - Any clash test, or all tests at once. Clash Detective folders and result groups are read, and group names are kept.
  • Export scope - Filtered results, Checked clashes (ticked in the list), or Navisworks selection (clashes whose two items are selected, e.g. after picking results in Clash Detective).
  • Filters - Status (incl. "Open"), clash type, discipline, severity, level, include/exclude resolved.
  • Parameter filter - Filter by any element parameter of the clashing items, e.g. a Revit Zone parameter: pick *Zone*, then *Zone 3*, and only the clashes in Zone 3 remain. Parameters are found on the clash elements automatically, and one named "Zone" is preselected. *Match on* sets which item must have the value: Item A or Item B, both items, only Item A, or only Item B. The values show in a grid column and in the reports, and Select shown items selects every clashing element of the listed clashes in Navisworks.
  • Global search - Searches clash name, element name/type/category/family, model, layer, level, zone, system, element ID, GUID, coordinates, comments, and more. Every term must match, and "quoted phrases" are supported.
  • Severity rules - Configurable. Hard clashes are rated by penetration depth (defaults Critical ≥ 100 mm, High ≥ 50, Medium ≥ 25, else Low). Clearance clashes are rated by remaining gap (defaults Critical < 25 mm, High < 50, Medium < 100, else Low). You set the severity used for duplicates.
  • Disciplines - Derived by keyword rules from the model file name, category, system and name (Structural, Mechanical, Plumbing, Electrical, Fire Protection, Architectural, Civil). The rules are editable.
  • Analytics - KPIs, coordination health score, charts by status, severity, discipline, discipline pair, level (ordered by elevation), test and model, a level × severity heatmap, a discipline A × B matrix, similar-clash groups, and auto-generated key findings.
  • Clash images - Per clash: a 3D view framed from front-right-top and an optional plan view. Item A and Item B are coloured. Around them the image shows only the elements within the zoom radius, ghosted (*Around the clash show*: nearby elements, only Item A and Item B, or the whole model). Everything else is hidden just for the capture and shown again afterwards. Markup is added (clash number, severity, marker ring, distance callout, A/B legend, coordinates). Alternatively, use the Clash Detective viewpoint image.
  • PDF report - Cover, contents with page numbers, executive summary, statistics, levels/tests/models, heatmap, similar groups, clash list, one or two clash detail pages per clash, model information, methodology and revision history. Every section can be switched on or off. Page sizes: A4, A3, Letter or custom, portrait or landscape.
  • HTML dashboard - A single offline file with overview, clash cards/table, statistics, heatmap, groups, and models & method. It has live filters and search, drill-down from charts, a clash detail viewer (keyboard ←/→/Esc), CSV export and print.
  • Navisworks XML & HTML - Optional template outputs in the Navisworks formats. The Navisworks XML is the Clash Detective XML report layout: tests, summary, results with clash point, level, dates, items with Element ID, layer, path and smart tags, plus comments. The Navisworks HTML is the tabular report, one row per clash with its image and both items. Both contain only the clashes in the export scope, so every filter applies (e.g. only Zone 3). Images go to a <report>_files folder beside them.
  • Templates - Named templates hold branding (logos, colours, fonts, header/footer), sections, page layout, rules, images and output options. You can create, duplicate, rename, delete, import and export them.
  • Project info - Project name/number, client, contractor, consultant, prepared/checked/approved by, revision, stage, notes and revision history. Remembered per Navisworks file.
  • File naming - Token pattern, e.g. {Project}_ClashReport_{ClashTest}_Rev{Revision}_{Date}. Tokens: {Project} {ProjectNumber} {ClashTest} {Revision} {Date} {Time} {Status} {Discipline} {Client} {Template} {Count}.
  • Preview & check - Estimated pages, images and charts, the section list, and a report quality check (missing project info or logos, clashes without properties or level, output folder, PDF engine, files that will be overwritten). "Open layout preview" shows the paged report in the browser without capturing images.
  • Batch / automation - A hidden add-in command for scripted or scheduled reporting (see below).
