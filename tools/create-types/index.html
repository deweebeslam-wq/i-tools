Create Types

Releasedi-Tools for Revit

Create, edit, bulk-build, import/export and audit family types — loadable and system families.

What it does

Smart Type Generator is a general-purpose type-management workbench: create new types (one-by-one, bulk-pasted, or by generating every combination across dimension ranges), edit/duplicate/rename/delete existing types, compare types side by side, audit a family for near-duplicates, and round-trip type data through Excel (export, import, and sync-compare against a spreadsheet). It works on both loadable families and system families (walls, floors, etc.).

When to use it

Building a full catalogue of section sizes for a structural family from a size list, keeping project types in sync with an Excel type schedule, bulk-renaming or bulk-deleting types, auditing a family for accidental duplicate/near-duplicate types, or duplicating an existing type as the starting point for a new one.

How to open it

Click Modeling Tools → Create Types on the ribbon.

Features

  • Left panel
    • Category list — Chooses the category to work in
    • Refresh (↻) — Re-reads categories from the active project
    • Family combo — Chooses the loadable family or system entry within the category
    • Defining Parameters — Ticks which parameters make a type unique
    • Audit — Scans the family for duplicate dimensions empty values and near-duplicate names
    • Name Template — Builds new type names from tokens
    • Reusable templates — Saves/loads/deletes a named setup of params+naming+maps+ranges+constants
  • Right panel
    • Existing types grid — Lists current types with tick column and defining-value summary
    • Duplicate → editor — Prefills bulk area from one ticked type
    • Compare — Produces a side-by-side parameter diff of ticked types
    • Export Excel — Writes existing types to a workbook
    • Import Excel — Loads types from a workbook into the bulk area
    • Sync Excel — Compares a workbook against project types
    • Type filter — Filters the existing types grid
  • Bulk create
    • Ranges → generate combinations — Builds every combination across parameter ranges
    • Parameter mapping — Aliases a bulk column header to a real family parameter
    • Constants — Applies a fixed value to every created/updated type
    • Bulk text box — Free text one type per line columns=ticked params
    • Rename ticked (Find/Replace) — Renames ticked existing types by text substitution
    • Delete — Deletes ticked existing types
    • Update existing on name match — Controls whether Create also updates same-named types
  • Preview
    • Live preview list — Shows names that will be created/updated
  • Report
    • Report grid — Shows Type/Status/Message from the last operation
  • Footer
    • Validate — Dry-checks the current bulk request without writing
    • Create / Update — Writes types to the model
