Excel to Views

Releasedi-Tools for Revit

Recreate an Excel worksheet as an editable drafting view, legend or schedule — same fonts, colours, borders and merges.

What it does

Rebuilds an Excel worksheet inside Revit so it looks like the worksheet — fonts, bold/italic/underline, colours (theme colours and conditional formatting included), borders, merged cells, column widths, row heights, number formats, alignment, wrapping and rotation, and its charts (column, bar, line, area, pie, doughnut, scatter — redrawn from their data) — as editable native elements: a Drafting view or a Legend view (text notes, detail lines, filled regions), a schedule whose header is the worksheet (static table), or a real model schedule whose columns come from the Excel headings. No Excel installation needed.

Pick an .xlsx, a worksheet and a range; the preview shows exactly what will be drawn. The sheet is rebuilt from native, editable elements — text notes for the cells, detail lines for the borders, filled regions for the backgrounds — keeping column widths, row heights, merged cells, fonts, bold / italic / underline, colours (theme colours and conditional formatting included), number formats, alignment, wrapping and rotation. Styles are reused by name, so text types and line styles never pile up. A generated view remembers its workbook: update it later and only its own elements are replaced (hand edits are detected first), or make a new version. Everything is one Ctrl+Z; cancel rolls back. No Excel installation needed. Modeless.

When to use it

- Putting a general-notes table, a door/beam/rebar schedule kept in Excel, or a colour legend onto sheets so it looks like the Excel original. - Building a native Revit schedule laid out like an Excel table (headings, order, widths, decimals, totals) and checking which Excel rows have no element in the model. - Re-running after the Excel file changes: only the generated elements are replaced.

How to open it

I-TOOLS tab → Annotation pulldown → Excel to Views. Opens as a modeless five-step window (singleton — reopening brings the existing window forward).

Features

  • Step 1 File
    • Browse button — Picks an .xlsx / .xlsm workbook (a workbook open in Excel can be read; .xls must be saved as .xlsx first)
    • Reload button — Reads the workbook again after you saved it in Excel
    • Worksheet dropdown — Chooses the sheet to convert
    • Range — Used range (cells with text, fills or borders), Print area, or a typed range such as A1:H40
  • Step 2 Preview
    • Preview — Draws exactly what will be built, charts included, with Excel column letters and row numbers; Ctrl + mouse wheel zooms
    • Selecting cells — Drag across the sheet, Shift+click to extend, drag over column letters / row numbers for whole columns / rows, the corner box or Ctrl+A for all, Esc to clear; the selection stays visible (green frame, address and size, the rest dimmed)
    • Crop to selection button — Keeps only the selected cells (and the charts inside them) and cuts the rest
    • Clear selection button — Removes the selection without cropping
    • Cell grid checkbox — Shows the cell grid in the preview only (never drawn in Revit)
    • Whole used range button — Goes back to the whole used range
    • Notes list — Everything that cannot be reproduced exactly (pattern fills, rich text, text wider than its cell, data bars, formulas without a saved result …)
  • Step 3 Output
    • Drafting view / Legend view / Schedule — same-shape table / Schedule — model elements — Chooses what is built (a Legend needs one existing legend in the project to copy, because Revit cannot create the first one)
    • View name textbox — Name of the new view or schedule
    • Create a new view / Update a view made earlier / New version — Update replaces only what Excel to Views generated (your own additions stay; hand edits are detected first); New version makes "Name v2"
    • Model schedule columns — Category, an Excel column → Revit field grid (matched automatically, editable), Sort by, Compare by, Itemize, Grand total
  • Step 4 Settings
    • Table size — As Excel at 100 %, Excel page-setup scale, fit to a width or height in mm, or a custom factor
    • Text size %, View scale, Top-left corner X / Y
    • Content checkboxes — Hidden rows / columns, Excel gridlines, skip white fills, conditional formatting, rows fit their largest font, include charts
    • Advanced — Text wider than its cell (narrow / wrap / leave), narrowest width factor, Excel-style spill, auto-fit rows, padding and indent, fallback font, line weight per border weight, text-size fine-tune, what to do when the view name exists, open the view after
  • Step 5 Convert
    • Convert button — Builds the output in one undoable step; Cancel in the progress window rolls everything back
    • Report — Cells processed, elements created, types and styles created / reused, what was not reproduced, warnings, errors, time
    • Open view button — Opens the generated view or schedule
    • Copy report button — Copies the report to the clipboard
