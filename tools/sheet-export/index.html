Sheet Export

Releasedi-Civil

Tick layouts, pick a folder, Start: one PDF per layout, a combined PDF, one plain AutoCAD DWG per layout (model space + that layout), and one DWG with every layout named after the drawing - Civil 3D objects converted as EXPORTC3DDRAWING converts them. Runs in the background (AutoCAD Core Console) while you keep working; PDF preset, plot style, page setup, DWG format, xrefs, feature lines, purge, audit, file naming and presets in the window

What it does

One window in place of EXPORTC3DDRAWING, opening its result, a split-layouts LISP and a separate PDF publish. The work runs in the background, in AutoCAD Core Console (accoreconsole.exe - Civil 3D without a window, in a process of its own), from a copy of the drawing's file. You keep working in Civil 3D - in the same drawing too, and you can save it - while the window shows a progress bar, the step it is on ("PDF 3 of 10: Sheet_03") and a live log. Closing the window while an export runs only hides it: ICIVILSHEETEXPORT brings it back, and the command line says when the export has finished. Stop stops after the file being written. While it is idle the window follows the active drawing; Refresh rereads the layouts, page setups, PDF plotters and plot style tables.

How to open it

Click Sheet Export on the i-CIVIL ribbon tab, or type ICIVILSHEETEXPORT at the command line.
