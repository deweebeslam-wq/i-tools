Set Pipe Cover

Releasedi-Civil

Type a start and end cover, centre depth or invert depth - measured down from the surface - once for any number of pipes; each pipe's elevations come from its own surface and size

What it does

Set Pipe Cover sets a target depth below the surface; it does not move pipes by an amount, and it never takes an elevation above a datum. Select any number of pipes - pick, window, crossing, or a selection made before the command (Enter with nothing selected selects nothing, never every pipe) - choose what to set, then type a start value and an end value once, in the drawing's units. The end value follows the start value until it is typed in, so one value for both ends is: type it, Enter.

- Three measures, all depths below the surface at each end, chosen with *Set by* (C, E, I): - Cover, as Civil 3D measures it: down to the top outside of the pipe - the crown plus the wall - which is what Pipe Properties reports as Start Cover and End Cover. - Centre depth: down to the centreline. - Invert depth: down to the invert, the inside bottom of the pipe.

The named level goes to the ground less the depth at that end; centreline, invert and crown follow from the pipe's own inside and outside heights (and its part's base point, when it states one). Nothing is carried over from the old elevations: the grade is whatever the two depths make it. Each measure keeps its own values, so a cover is never taken for a depth when the measure is switched. Set by a depth, the dialog shows the cover it gives, a pipe whose top would stand above the surface is warned about, and only a cover needs the pipe's outside height. - Each pipe on its own: its own ground at its own two ends, its own size - a 300 and a 900 in one selection each get their own inverts for the same cover, and their own centrelines for the same invert depth. - Surface: each pipe's own reference surface (the one Pipe Properties measures cover from), else its network's. Pipes with neither are measured from a surface chosen once in the dialog, which asks only when that is needed. Reference surfaces are never changed. - Checked against Civil 3D: for a pipe with its own reference surface, the cover i-CIVIL works out at its present position must match the cover Civil 3D reports before anything moves, whichever measure is being set - otherwise the pipe is left alone and both figures are shown - and Civil 3D's covers are read back after the change and compared with those asked for, or with those the depths give. - Only the vertical changes: a straight pipe's start and end points are set at the same X and Y; a curved pipe's curve is stated again with the new end elevations, and proven to be the same arc - circle, ends, direction - through Civil 3D's own GetArc2d before it is used. Part, size, style, rules, network and connections are not touched. Segmented, flexible and data-shortcut pipes are left alone and named. - One transaction, one undo: each pipe is read back as it is written - ends in plan and height, straight or curved as it was, the same connections - and all of them again once all are set. A pipe that fails undoes the whole attempt, which is repeated without it, so no pipe is ever kept half set; after five such failures the run stops and changes nothing. One UNDO reverts the whole operation. - Report: counts, covers, and every pipe not updated with the reason and its handle, on the command line; an alert as well when something failed after Apply. Grades that reverse or go level, inverts now below a structure's sump, and any unselected pipe moved at a shared structure are reported as warnings. Every figure is in the log.

The arithmetic is PipeCoverMath and the dialog's rules SetPipeCoverOptions, both in Core and unit-tested; the drawing side is PipeCoverReader, PipeCoverCurves, PipeCoverWriter and SetPipeCoverTool.

---

How to open it

Click Set Pipe Cover on the i-CIVIL ribbon tab, or type ICIVILSETPIPECOVER at the command line.
