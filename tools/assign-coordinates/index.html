Assign Coordinates

Releasedi-Tools for Revit

Write exact survey (shared-coordinate) values to Coord_E / Coord_N / Coord_Z on elements.

What it does

Coordinate Manager writes exact survey (shared-coordinate) X/Y/Z values into three shared parameters — Coord_E, Coord_N, Coord_Z — on elements you choose, creating those parameters from a shared parameter file first if they don't already exist. It's a way to bake real-world survey coordinates onto elements as readable parameter values instead of leaving them only computable from geometry.

When to use it

Populating coordinate parameters for a schedule that needs to show real survey easting/northing/elevation per element (e.g. structural columns, survey points, MEP equipment), or exporting a CSV of element coordinates for a surveyor or GIS handoff.

How to open it

Click the Assign Coordinates button in the "Coordinate Manager" panel.

Features

  • Title Bar
    • Scope: Entire Model / Selected Elements — Chooses which elements are candidates for coordinate assignment
  • Toolbar
    • Assign Coordinates button — Writes Coord_E/Coord_N/Coord_Z to every element in scope and ticked categories
    • Inspect Element button — Lets you pick one element in the viewport to preview its coordinates without writing anything
    • Export CSV button — Exports the last results grid to a CSV file
    • Validate Project button — Checks that the active project location / shared coordinate setup is configured
    • Cancel button — Stops a running coordinate assignment
    • Dry Run checkbox — Simulates the full run including the transaction, then rolls it back
  • Categories Panel
    • Search box — Filters the category checklist by name
    • All / None buttons — Ticks or clears every visible category
    • Refresh (↺) button — Reloads the category list from the current document
    • Category checklist — Chooses which categories are included in the assignment run
  • Settings Bar
    • Precision field — Sets the number of decimal places written to the coordinate parameters (1-6)
    • Unit radio buttons — Sets the display unit for output values: Metres or Feet
    • Batch size field — Sets how many elements are processed per transaction batch
    • Overwrite existing checkbox — Chooses whether elements that already have coordinate values get recalculated
    • Save button — Persists the current settings to disk for next time
  • Results Tab
    • Results grid — Lists every processed element with its computed coordinates and status
  • Inspector Tab
    • Element inspection readout — Shows the diagnostic coordinate detail for the last picked element
  • Log Tab
    • Run log — Shows a scrollable plain-text history of the last run
