i-SELECT BY ID

Releasedi-Navis

A small tool window. Paste Revit Element IDs and select them in Navisworks in one click, then optionally hide the rest, box them or zoom to them.

What it does

i-TOOLS → Select By ID opens a small tool window (clicking again brings it to the front):

1. Paste one or many Revit Element IDs. They can be separated by commas, spaces, semicolons, tabs or new lines, e.g. 123456, 456789 or a column copied from Excel. Duplicates, empty values and anything that is not a whole number are removed, and the pane shows the count (*3 IDs detected · 1 invalid value*). 2. Click SELECT ELEMENTS (or press Ctrl+Enter). Every element with those IDs is selected in Navisworks. 3. Optional:

IDs that are not found are listed and can be copied. An ID that exists in several loaded models selects every occurrence; the pane lists those IDs, and the *Model* filter (shown only when several models are loaded) narrows the search to one model. The last 10 searches are under Recent, which can be switched off in ⚙.

The first search builds an index of Element ID → Navisworks element, using one native search per model; later searches reuse it until models are loaded or unloaded. The ID is read from Element ID › Value, then Element › Id and the other properties listed under ⚙. If none of them exists in a model, an ID-like numeric property is detected automatically.

How to open it

Click i-SELECT BY ID in the Selection on the i-TOOLS ribbon tab in Navisworks.

Features

  • Hide others: only the found elements stay visible. Show all or Esc undoes it, and nothing is written to the model files.
  • Selection box: a section box is placed around the elements with a margin, and the view zooms to them. Remove box restores the previous sectioning.
  • Zoom to selection: frames the current selection at any time.
