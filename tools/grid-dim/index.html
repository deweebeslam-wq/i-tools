Grid Dim

Releasedi-Tools for Revit

Auto-dimension selected grids (segmented + total).

What it does

Instantly builds two dimension strings — a segmented run between every consecutive grid, plus one overall total span — for every parallel grid of the orientation(s) you touch in the active view. No dialog, just one click and two picks.

Select grids in a 2D plan view and run. Creates a segmented dimension string (between each consecutive grid) plus a total span (first→last, offset further out). No dialogs — hardcoded 2 ft / 4 ft offsets. Mixed N-S / E-W selections are split and dimensioned independently; arc grids and grids not shown in the view are skipped.

When to use it

- Fast grid dimensioning on a structural or architectural plan without manually stringing together dimension references. - Re-dimensioning after adding or removing a grid line — picking just one grid re-dimensions the whole parallel set.

How to open it

I-TOOLS tab → Annotation pulldown → Grid Dim, in a Floor/Ceiling/Engineering/Area plan, Elevation, Section, or Detail view.

Features

  • Selection
    • Pre-selection — Uses grids already selected in the model instead of prompting to pick
    • Interactive pick — Prompts to pick one grid per axis when nothing is pre-selected
  • Behavior
    • Auto-expand to parallel grids — Picking one grid on an axis dimensions every other visible, straight grid on that same axis
    • Mixed-orientation handling — Picking both a N-S and an E-W grid dimensions both axes independently in the same run
    • Side-of-click placement — The point you click after picking grids decides which side the dimensions land on
    • Arc grid skipping — Arc (non-straight) grids are silently excluded from dimensioning
  • Output
    • Segmented dimension string — One dimension segment per consecutive pair of grids, offset 2 ft from the outermost grid
    • Total dimension string — First-to-last grid span only, offset 4 ft from the outermost grid
