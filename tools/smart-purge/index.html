Smart Purge

Releasedi-Tools for Revit

Deep model cleanup beyond Revit's native Purge Unused.

What it does

Smart Purge goes far beyond Revit's built-in "Purge Unused" command. It scans the model with over two dozen specialised checks — unused line styles, fill patterns, view filters, view templates, subcategories, imported CAD styles, duplicate materials, empty worksets, unplaced rooms/areas, and more — and lets you review, select and delete everything you want in a single undo step. A separate "Empty Parameters" sweep finds project/shared parameter definitions that hold no data anywhere in the model and can safely be unbound.

Scans for unused line styles, fill patterns, view filters, view templates, subcategories, CAD pollution, empty worksets, duplicate groups, empty parameters and more — preview first, then remove in one undoable step.

When to use it

Before archiving or handing off a model, before exporting to IFC/NWC, after a big design change that leaves orphaned styles/filters behind, or as periodic housekeeping to keep file size and browser clutter down.

How to open it

Click Cleanup & QA → Smart Purge on the ribbon. The window is modeless — you can keep it open and keep working in Revit.

Features

  • Toolbar
    • Scan (F5) — Runs every enabled scanner against the current document
    • Select All / Deselect All — Ticks or clears every candidate
    • Simulation — Runs the purge in a transaction that always rolls back so nothing is written
    • Risk tolerance selector — Controls which risk-tier items are offered and whether confirmation is required
    • Purge checked (Del) — Deletes every ticked still-valid candidate in one undo step
    • Safe clean — Multi-pass purge of Safe-risk items only up to 10 passes
    • Ultra clean — Multi-pass purge of Safe + Low-risk items
    • Empty Parameters — Opens the dedicated Empty Parameters sub-window
  • Scope panel
    • Scanner checklist — Enables/disables individual scanner categories for faster scans
    • All / None — Bulk enable or disable every scanner
  • Result list
    • Filter box — Free-text search across current candidates
    • Group Toggle group — Selects or deselects every item in one category group
  • Preview pane
    • Highlight usage — Overrides referencing elements in the active view in red
    • Reset — Clears the highlight overrides
  • Scanners
    • Families/Types scanners — Finds unused family types and unused families
    • Views/Annotation scanners — Finds unused views schedules empty sheets and unused legends
    • Styles/Patterns scanners — Finds unused/duplicate line styles line patterns fill patterns subcategories and imported DWG styles
    • Filters/Templates scanners — Finds unused view filters view templates and scope boxes
    • Materials/Assets scanners — Finds unused materials appearance assets and duplicate materials
    • Imports scanners — Finds CAD imports raster images and point clouds
    • Worksets/Groups scanners — Finds empty worksets unused groups duplicate groups and empty assemblies
    • Spatial scanners — Finds unplaced rooms and unplaced areas
  • Empty Parameters window
    • Scope — Chooses which elements are read: entire model active view or selection
    • What to read — Chooses Instance/Type/Family/Built-in parameter passes
    • Scan (F5) — Runs the empty-parameter sweep
    • Simulation — Dry-runs the delete in a rolled-back transaction
    • Delete Selected Parameters — Removes the parameter binding (never an element)
    • Filters — Search/category/type filters plus Deletable only and Whole-parameter only
    • Select All / Clear All — Selects every deletable visible row or clears selection
