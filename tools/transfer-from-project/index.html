Transfer From Project

Releasedi-Tools for Revit

Copy sheets, views, legends, schedules, templates & filters from another project.

What it does

Transfer From Project brings documentation — sheets, drafting views, legends, plans, sections, schedules, view templates and view filters — from another Revit project into the currently active model. Rather than a raw copy-paste, each item type is recreated the "correct" way for its kind (plans/sections are rebuilt on a matching level or section box and refilled with their annotations; sheets are rebuilt with titleblock, sheet annotations and viewports at their original positions), and every item is reported as Copied, Renamed, Merged, Partial, Skipped, or Failed.

Bring documentation from an old project version (or any other project) into the active model. Source can be an open document, a loaded link, or an external RVT opened detached in the background (never saved). Drafting views and legends arrive WITH their contents; plans and sections are recreated (level matched by name / section box rebuilt) and their annotations copied in; sheets are rebuilt with titleblock, sheet annotations and viewports at the original positions. Name conflicts: skip, rename with suffix, or merge annotations into the existing view.

When to use it

Migrating documentation from an old project version or phase into a new central file, borrowing a sheet set, schedule, or drafting-view library from a sister/standards project, or bringing over a titleblock's sheet layout from an archived project.

How to open it

Click "Transfer From Project" on the I-TOOLS ribbon, Utilities panel, with the project you want the content copied INTO already open and active — if no document is active, a message tells you to open the target project first. Opens a modeless singleton window.

Features

  • Entry
    • Ribbon Button — Opens the modeless Transfer From Project window; requires an active target document
  • Source Selection
    • Open Document Radio + Combo — Uses another currently open, non-linked project as the source
    • Loaded Link Radio + Combo — Uses one of the target's loaded Revit links as the source
    • External RVT Radio + Path + Browse — Opens an external .rvt file detached in the background (never saved) as the source; can't be the same file as the active target
    • Scan Source Button — Reads the source document and builds the content tree, grouped by kind
  • Content Tree
    • Search Box — Live-filters the content tree by item name
    • All Button — Checks every currently visible item in the tree
    • None Button — Unchecks every currently visible item in the tree
    • Group Checkbox — Tri-state checkbox on a group header (Sheets, Drafting Views, Legends, Schedules, Plans, Sections, View Templates, View Filters) that checks/unchecks all its children
    • Item Checkbox — Marks an individual sheet/view/schedule/template/filter for transfer
    • Sheet Auto-Check Dependents — Checking a Sheet automatically checks the views placed on it (one-way)
  • Options
    • Conflict - Skip Existing — Leaves an existing same-name item (or same sheet number) untouched and transfers nothing for it
    • Conflict - Rename Copy — Appends an editable suffix to the incoming item's name so it doesn't collide with an existing one
    • Conflict - Merge Annotations — Copies incoming annotations into the existing same-name view instead of creating a new one; only applies to Drafting Views/Legends/Plans/Sections, falls back to Skip for Filters/Templates/Schedules/Sheets
    • Name Suffix Field — Editable suffix text used by the Rename Copy conflict mode
    • Copy Annotations Into Recreated Plans/Sections — Copies the source plan/section's owned annotations (tags, dimensions, etc.) into the newly recreated view
  • Run
    • Transfer Button — Runs the transfer pipeline for every checked item
    • Cancel Button — Stops the run after the item currently in progress
    • Progress Bar / Status Text — Shows live (current/total) progress and the item being processed
  • Results
    • Results Grid — Lists Kind / Name / Status / Note for every processed item, color-coded by status
    • Export Report Button — Writes the Results grid to a report file
  • Content Handling
    • Filters/Templates/Schedules Transfer — Copied document-to-document as-is, one transaction per item; renamed automatically on conflict
    • Drafting Views Transfer — Creates a new blank Drafting view in the target, then copies all the source drafting view's owned content into it
    • Legends Transfer — Duplicates an existing legend view already in the TARGET as a seed (API can't create legends), empties it, then fills it with the source legend's content; skipped with a note if the target has no legend view at all
    • Plans Transfer — Recreates a Floor Plan or Ceiling Plan on the target level matched BY NAME to the source's level; fails if no matching level exists
    • Sections Transfer — Recreates a Section view by rebuilding the section box from the source view's crop box and right/up/view directions
    • Sheets Transfer — Transferred last; titleblock matched by Family:Type name (falls back to any/none); titleblock parameter values copied by name; sheet annotations, viewports (only for views transferred this run) and schedule instances (for schedules transferred this run) are recreated
