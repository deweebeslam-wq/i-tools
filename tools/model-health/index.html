Model Health

Releasedi-Tools for Revit

Enterprise BIM QA/QC scan: statistics, performance, compliance, coordination and documentation.

What it does

Model Health Analyzer runs a weighted QA/QC scan of the open model across performance, BIM compliance, coordination, and documentation, producing a 0–100 health score and a filterable issues list. It also includes a full manual observation-tracking workflow (with screenshots, markup, and a shared multi-user repository) for issues a scan can't catch automatically.

Async scan engine collects file size, view/sheet/warning/family/CAD/link/group/workset/design-option/schedule/level/grid/room counts. Weighted score (Perf 30% / Compl 30% / Coord 25% / Docs 15%). Interactive issues grid + per-category cards. Modular IModelAnalyzer interface — plug in more analyzers.

When to use it

Periodic model-health audits, pre-coordination-meeting cleanup, generating a client-facing health report, or logging and tracking non-clash QA/QC observations (naming, documentation gaps, missed tags) across a project team.

How to open it

I-TOOLS ribbon → "Model Health" panel → "Model Health" button.

Features

  • Health Score tab
    • Run Scan button — Runs the full weighted QA/QC scan across all registered analyzers
    • Cancel button — Stops a running scan
    • Export button — Exports the health report
    • Copy button — Copies a summary of the scan to the clipboard
    • Score cards — Shows Overall Score plus Performance/BIM Compliance/Coordination/Documentation sub-scores (0-100, color banded)
    • Statistics panel — Lists 16 model metrics (file size, views, sheets, warnings, families, CAD imports, links, groups, worksets, design options, schedules, levels, grids, unplaced/unenclosed rooms)
    • Issues filter box — Free-text search across the issues grid
    • Issues grid — Lists issues with Severity/Category/Title/Description/Suggested Fix, sortable columns
    • Select button (per issue row) — Selects and zooms to the issue's linked element in Revit
  • Observations tab
    • New Issue button — Opens a blank draft form to create a manual observation
    • Refresh button — Reloads the observations list
    • Batch Capture button — Regenerates element-centered screenshots for every issue currently visible in the grid (respects filters)
    • Template dropdown — Chooses the report template used for export
    • Observations export button — Exports the observation log using the selected template
    • Full Report button — Exports a combined Model Health + Observation Log report (requires a recent scan; disabled under RFI template)
    • Status/Severity/Discipline filter dropdowns — Filters the observations list by these facets
    • All (clear filters) button — Clears all observation filters
    • Free-text filter box — Instant search across observation rows
    • Project Notes expander — Free-form project-level notes printed as a preamble on exported reports
  • Observations - draft form
    • Title/Description/Recommendation fields — Free text fields describing the new observation
    • Severity/Discipline dropdowns — Classify the new observation
    • Smart capture checkbox — Element-centered capture: temporary section box (3D) or crop region (plan/section) fitted around the issue, rolled back after the shot
    • Auto-isolate checkbox — Isolates the linked element during capture
    • Multi-angle checkbox — For 3D views, also saves Front/Top/ISO/Detail angle screenshots
    • Clash look checkbox — Navisworks-style colorization: issue elements red/green, context transparent
    • Overlay checkbox — Stamps issue ID, severity, author, and date into the image corner
    • Offset dropdown — Section box offset around the issue (mm) for capture
    • Pad % dropdown — Crop region padding as a percent of issue size
    • Res dropdown — Output image width in pixels (PNG, lossless)
    • Capture View button — Takes the screenshot using current capture options
    • Cancel/Save Issue buttons — Discards or saves the new observation
  • Observations - detail pane
    • Title/Status/Severity header fields — Editable identifying fields for an existing observation
    • Full Size button — Opens the screenshot at full size in a viewer window
    • Markup button — Opens the Markup dialog to annotate the observation's screenshot
    • Discipline/Assigned to fields — Editable classification and assignment fields
    • Description/Recommendation fields — Editable free text fields
    • Open in Revit button — Selects and navigates to the linked Revit element/view
    • Isolate button — Temporarily isolates the linked element in its view
    • Re-capture button — Retakes the screenshot for this existing observation
    • Comments thread + Add — Adds a timestamped comment to the observation
    • Comment delete — Removes a comment from the thread
    • Tags + Add Tag — Adds a free-text tag chip to the observation
    • Tag delete — Removes a tag chip
    • Status history list — Read-only log of status transitions with timestamp and changed-by user
    • Delete/Save buttons — Deletes or saves changes to the selected observation
  • Markup dialog
    • Pen/Rect/Arrow/Text/Erase tools — Selects the active drawing tool for annotating the screenshot
    • Thickness presets (2/4/8/14) — Sets the stroke width for the active drawing tool
    • Pan/zoom controls — Pans and zooms the markup canvas
    • Undo/Clear buttons — Undoes the last stroke or clears all markup
    • Cancel/Save Markup buttons — Discards or saves the annotated image
  • Repository tab
    • Create Repository button — Creates a new shared issue repository at a chosen location
    • Connect button — Connects to an existing shared repository
    • Disconnect button — Disconnects from the current repository
    • Backup button — Backs up the repository database
    • Repair button — Attempts to repair a damaged repository database
    • Open Folder button — Opens the repository's file location in Explorer
    • Refresh button — Reloads repository status and diagnostics
    • Auto-connect checkbox — Automatically connects to the last-used repository on startup
    • Projects grid — Lists projects stored in the connected repository
    • Diagnostics card — Shows machine/user/storage mode/read-write access/store existence/issue counts/last error for troubleshooting
    • Recent Repositories list + Connect — Quick-reconnect to a previously used repository
