Compare Files

Releasedi-Tools for Revit

Compare the active model (File A) against another .rvt on disk (File B).

What it does

Compare Files performs an element-level diff between the currently open model (Source A) and another Revit model on disk, a linked model, or a nested link (Source B). It reports every element that was Added, Deleted, Moved, or has Modified parameters, with an expandable old-vs-new parameter table per element, and can color/isolate the differences directly in the 3D view. File B is opened detached and read-only and is never saved.

Opens File B detached + read-only, extracts every element from both models, and reports what was Added / Deleted / Moved / Modified (instance + type parameters, family/type renames). Expandable parameter diff per element. Export CSV or human-readable TXT. File B is never saved.

When to use it

Coordination QA between design revisions, verifying what changed between a consultant's linked model and a previous version, auditing before/after a big edit, or producing a change-log export for a project record.

How to open it

Click Cleanup & QA → Compare Files on the ribbon. The window is modeless.

Features

  • Setup panel
    • Source A / Source B mode — Chooses active model linked model or external file as each diff source
    • Browse — Picks an external .rvt file from disk
    • Model only — Restricts diff to model-category elements
    • Include nested links — Recurses into links inside links when listing sources
    • Compare geometry — Adds volume/area/length hashing for more accurate matching
    • Move tolerance — Sets the distance threshold below which a move is ignored
    • Refresh Links (⟳) — Reloads the list of currently loaded links
  • Summary
    • Badges (Added/Deleted/Moved/Modified) — Shows live counts and jumps to that tab
    • Legend — Shows the 8 change-type colors with live counts
  • 3D tools
    • Color 3D by change type — Graphic-overrides the change set in the active view
    • 3D View — Creates/reuses a FileDiff Changes 3D view isolated and colored on all changes
    • Isolate by change type — Section-box isolates elements of one change type
    • Clear — Clears all viz overrides
    • Category filter — Restricts all tabs to one category
    • Search box — Instant search by category/family/type/level/id
  • Profiles
    • Save/Load/Delete profile — Stores or restores a named comparison setup
  • Parameter picker
    • Parameter checklist — Chooses exactly which parameters drive the diff
    • All / None — Bulk selects or clears parameters
    • Drag to reorder — Changes display/priority order of parameters
  • Parameter mapping
    • Add / Remove mapping — Maps a Source A parameter name to a different Source B parameter name
    • Apply — Applies the mapping table to the diff
  • Results
    • Added/Deleted tabs — Lists elements only in B or only in A
    • Moved tab — Lists elements whose position changed beyond tolerance
    • Modified tab — Lists elements with parameter differences, expandable per element
    • Row actions Zoom/Isolate/Select — Navigates Revit to that element
  • Warnings panel
    • Toggle warnings — Shows/hides skipped or problem elements from extraction
  • Footer
    • Run Diff — Extracts both models and computes the diff
    • Cancel — Stops an in-progress diff run
    • Export CSV — Exports the report as one CSV per change type
    • Export TXT — Exports a human-readable summary
