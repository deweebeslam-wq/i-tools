i-CLASH TEST BUILDER

Releasedi-Navis

A tool window. Pick Sets (or models, or disciplines), tick what should clash in an interactive clash matrix, preview the tests and create them in Clash Detective. Existing tests are detected and never duplicated.

What it does

i-TOOLS → Clash Test Builder opens a tool window with four steps:

1. What do you want to coordinate?

2. Select Sets.

3. Clash matrix.

4. Test settings: type (Hard, Hard conservative, Clearance, Duplicate), tolerance with unit, and Composite objects.

PREVIEW TESTS lists every test (expand one for its Sets and location). CREATE TESTS shows a final confirmation, then creates the tests with live progress. The matrix stays open afterwards and shows ✓ created, ⚠ existing and ✕ failed, with the reason for each failure.

Tests use the actual Navisworks Sets as their selections, so they follow the Sets when these change. Model tests use the model roots. Tests are added to Clash Detective but not run.

How to open it

Click i-CLASH TEST BUILDER in the Coordination on the i-TOOLS ribbon tab in Navisworks.

Features

  • Set vs Set: search and selection Sets against each other.
  • Model vs Model: whole loaded models, each pair once.
  • Full Coordination: discipline against discipline, using each discipline's Sets, or its model when it has no Sets.
  • Load template: applies a saved setup. Matching Sets are ticked, missing ones are listed, and nothing is created automatically.
  • Sets are listed in their Sets-window folders, with search, a tick box per group and per Set, and Select all / Clear.
  • Sets without a folder are grouped by a discipline guess from their name, or "Other".
  • Right-click to rename a group or move a Set to another group.
  • Every cell is one possible test. Click a cell to add or remove it; clicking a row or column name toggles the whole line.
  • Headers stay visible while the cells scroll, and the filter narrows rows and columns.
  • Cell states: ✓ will be created · – not selected · ⚠ already exists · ! cannot be tested (same Set on both sides, empty selection set, discipline without Sets) · = the same pair appears elsewhere.
  • *Structure vs MEP*, *Architecture vs MEP*, *Full coordination* and Smart suggestions only select cells.
  • The counters show possible, selected, existing and to create. The clicked cell shows its Sets, settings, status and an editable test name.
  • Naming - Pattern with tokens {Project} {GroupA} {GroupB} {SetA} {SetB} {CategoryA} {CategoryB} {TestType} {Tolerance} {Date} {Sep}, plus prefix, suffix, separator and case. {CategoryA} strips prefixes such as SS_ from Set names.
  • Existing tests - Keep (default; a test for the same Sets, or with the same name, is never duplicated), Update (type, tolerance and Sets are written into the existing test), or Create a new copy.
  • Organization - Top level, one folder, or one folder per row group. Navisworks does not let add-ins create Clash Detective folders, so an existing folder with that name is used; otherwise the folder name is put in front of the test name.
  • Ignore - Suggested exclusions found in the document (Grids, Levels, Rooms, …) plus your own wildcards. Nothing is ignored until you tick it.
  • Templates - Built-ins: *Standard BIM Coordination*, *MEP Coordination*, *Structural Coordination*. Your own templates store the Sets, matrix, type, tolerance, naming, ignore rules, organization and existing-test behaviour.
  • Property CSV - Optional. Any CSV (e.g. from i-PROPERTY EXPORT PRO) with mappable model, category and discipline columns improves grouping and suggestions.
