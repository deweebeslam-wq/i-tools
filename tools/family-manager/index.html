Family Manager

Releasedi-Tools for Revit

Batch rename families and types — manual operations or ElementCoder smart templates.

What it does

Family Manager batch-renames families and/or types across the project, either with simple manual operations (prefix/suffix/remove/find & replace) or with the same token-template + conditional-rule engine used by Element Coder. Every rename is shown in a live preview grid — nothing is written to the model until you click Apply — and name collisions are flagged and auto-numbered.

Loadable families and system family types. Manual mode: prefix/suffix/remove/find&replace with live preview. Smart mode: {OLD_FAMILY_NAME}/{CAT}/{SEQ:3} templates with conditional rules (ElementCoder engine). Collision auto-resolve, audit CSV, one-undo apply.

When to use it

Standardizing family/type names after merging content from another office or template, cleaning up "xxx Copy 1 / Copy 2" duplicate type names, applying a project naming standard to a whole discipline's families in one pass, or renumbering type names to match a coding scheme.

How to open it

Click "Family Manager" on the I-TOOLS ribbon, Utilities panel. Opens a modeless singleton window.

Features

  • Entry
    • Ribbon Button — Opens the modeless Family Manager window (singleton)
  • Toolbar
    • Section Combo — Chooses whether to work on Loadable Families (family+type rename) or System Family Types (type-only rename, family name is API-locked)
    • Scope Combo — Chooses which elements' types are collected into the grid: Entire Project / Active View / Current Selection
    • Rename Target Combo — Chooses Rename Types (one row per type) or Rename Families (one row per family, collapsing its types)
    • Categories Popup — Checklist of categories to load, with All/None buttons and a Load Selected action, to keep large models fast
    • Reload Button — Re-collects the currently ticked categories from the model
    • Filter Mode + Filter Text — Restricts which grid rows are shown and therefore renamed (Contains/Starts With/Ends With)
    • Select All / Select None Buttons — Toggles the row checkbox column for all currently shown rows
    • Export Excel Button — Exports the grid so New Family/New Type can be edited offline in Excel
    • Import Excel Button — Imports an edited spreadsheet back into the grid, matched by TypeId; imported rows become manual overrides
    • Apply Renames Button — Writes every previewed rename in a single transaction
    • Cancel Button — Cancels a running apply operation
  • Grid
    • Row Checkbox Column — Marks a row as selected for bulk actions
    • New Family Cell — Editable inline text box showing the family's new name; locked for system-family rows
    • New Type Cell — Editable inline text box showing the type's new name; locked for family-summary rows
    • Collision Highlight — Highlights rows whose target name duplicates another row's target name
  • Manual Tab
    • Target Combo — Chooses whether manual operations affect Family Name, Type Name, or Both
    • Add Prefix — Text prepended to the target name
    • Add Suffix — Text appended to the target name
    • Remove Substring — Removes the first occurrence of the given text from the name
    • Find / Replace — Replaces occurrences of Find text with Replace text
    • Case Sensitive Checkbox — Controls whether Find/Replace matching is case sensitive
    • Convert Case Combo — Applies a case transform last: UPPERCASE / lowercase / Title Case / Sentence case / PascalCase / camelCase / snake_case / SCREAMING_SNAKE / kebab-case
  • Smart Naming Tab
    • Global Family Template — Token template producing the default new family name for every row not overridden by a rule
    • Global Type Template — Token template producing the default new type name for every row not overridden by a rule
    • Suggest Button — Loads a saved template suggestion for the grid's dominant category (Doors/Windows/Walls/Pipes/etc.)
    • Zone Field — Optional text feeding the {ZONE} token in templates
    • Token Browser — Searchable, grouped list of every available token; double-click inserts it
    • Insert Target Combo — Chooses whether double-clicked tokens go into the Family or Type template
    • Favorite Toggle — Marks a token as a favorite for quicker access
    • Selected Row Parameters Panel — Lists every parameter key/value on the currently selected grid row, to help build {PARAM:name} tokens
    • Add Rule Button — Creates a new conditional rule with independent family/type template overrides
    • Rule Enabled Checkbox — Turns a conditional rule on or off
    • Rule Priority — Numeric order; lowest number wins when multiple rules match
    • Rule Family/Type Template — Overrides the global family and/or type template independently for matching rows
    • Remove Rule Button — Deletes a conditional rule
    • Condition Field/Operator/Value/Param Name — Defines one AND-ed condition of a rule (same field/operator set as Element Coder)
    • Add/Remove Condition Buttons — Adds or removes a condition from a rule
  • Status Bar
    • Stat Chips — Live counts of total types, pending changes, collisions, and manual overrides
    • Progress Bar — Shows apply progress
