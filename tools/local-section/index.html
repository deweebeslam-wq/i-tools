Local Section

Releasedi-Tools for Revit

Generate a 2D local cross-section detail from selected structural elements.

What it does

Smart Local Section lets you click one structural element in a plan view and instantly get a 2D local cross-section detail — a colored, dimensioned cut-away of that element plus the surrounding structural stack — placed directly on the plan. It replaces manually building a section view just to document one connection or condition.

When to use it

Documenting a beam/column/wall/slab connection for an RFI or shop-drawing coordination note, producing quick local structural sections at specific points without setting up and cropping a full section view.

How to open it

Click the big "Local Section" button on the "Smart Local Section" ribbon panel to run the main workflow, or click the ▼ dropdown next to it for the other options below.

Commands

Local Section
Generate a 2D local cross-section detail from selected structural elements. Click the large icon to run. Click ▼ for related tools.
Thin Cut (50 mm)
Run Local Section with a 50 mm cutting-plane depth (slabs, thin walls).
Standard Cut (100 mm)
Run Local Section with a 100 mm cutting-plane depth (default).
Thick Cut (250 mm)
Run Local Section with a 250 mm cutting-plane depth (thick walls, deep beams).
Update Sections
Scan all generated sections and refresh those whose source element has changed.
Section Settings…
Configure section depth, colors, annotations and placement options. Changes save automatically and are picked up on the next run of Local Section.

Features

  • Ribbon SplitButton
    • Local Section (main button) — Runs the pick-one-element-and-generate workflow using current saved settings
  • Ribbon SplitButton dropdown
    • Thin Cut 50mm preset — Runs the same workflow with section depth temporarily set to 50mm
    • Standard Cut 100mm preset — Runs the same workflow with section depth temporarily set to 100mm
    • Thick Cut 250mm preset — Runs the same workflow with section depth temporarily set to 250mm
    • Update Sections — Rescans previously generated sections and reports which are stale
    • Section Settings — Opens the configuration dialog for depth/colors/annotations/placement
  • Settings - Section Geometry
    • Section Cut Depth (mm) field — Distance along the element axis where the cut is made
    • Offset from Element (mm) field — Gap between the source element and the placed section detail
    • Gap Between Sections (mm) field — Minimum spacing enforced when placing multiple sections
    • Approx. Section Width/Height (mm) fields — Estimated section footprint used for collision detection during Automatic placement
  • Settings - Detail Boundary
    • Visible Above/Below Click (mm) fields — How much of the model is shown above/below the point you clicked
    • Depth Along Beam (mm) field — Thickness of the cut volume along the beam's axis
    • Min/Max Detail Width (mm) fields — Clamps the visible width perpendicular to the beam
    • Context Cut Length (mm) field — Caps the visible length of surrounding walls/slabs/foundations centered on the beam; 0 = unlimited; the selected beam is never cropped
    • Mirror section vertically checkbox — Flips the section up/down about the beam center
    • Mirror section horizontally checkbox — Flips the section left/right about the beam centerline
  • Settings - Workflow & Placement
    • Workflow Mode dropdown — Sets Concrete/Steel/Mixed workflow defaults
    • Placement Mode dropdown — Chooses On Element (click point)/Automatic (collision-avoiding)/Manual (you click a placement point)
    • Include Linked Models checkbox — Includes linked-model elements in the surrounding structural stack
  • Settings - Annotations
    • Add linear dimensions checkbox — Adds width/height dimensions to generated sections
    • Add spot elevation checkbox — Adds a spot elevation annotation at the section top
    • Add element tags checkbox — Adds element tags to the generated section
    • Show break lines checkbox — Shows zigzag break symbols on clipped context element edges
    • Annotation Scale (1:X) field — Sets the scale used for dimension/tag annotation sizing
    • Outline Line Weight dropdown — Sets the line weight used for fallback detail-curve outlines
  • Settings - Visual Style
    • Color Mode dropdown — Black & White vs Colored rendering of the section fills
    • Category Colors table — Shows the fill color assigned per category (edited via Export/Import JSON)
  • Settings footer
    • Export button — Exports current settings to a JSON file
    • Import button — Loads settings from a JSON file
    • Reset Defaults button — Restores all settings to their factory defaults
    • Save Settings button — Saves all current settings and closes the dialog
  • Update Report window
    • Summary pills — Shows counts of Up to date/Modified/Deleted sections found
    • Per-row checkbox — Selects a section for regeneration
    • Select All/Deselect All toggle — Bulk-selects or deselects all update-eligible rows
    • Cancel button — Closes the report without applying any updates
    • Update Selected button — Deletes and regenerates the checked stale sections
