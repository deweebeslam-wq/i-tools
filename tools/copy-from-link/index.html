Copy From Link

Releasedi-Tools for Revit

Copy elements from a loaded Revit link into the host model.

What it does

Copy From Link copies elements from a loaded Revit link directly into the host model — with category filtering, an optional crop/section-box spatial limit, automatic skipping of elements that already exist at the same position, and a debug preview mode that reports what would happen without changing anything.

Select a linked model + categories, optionally limit to the active crop/section box, and skip duplicates by position. Face-hosted families are re-placed as non-hosted at the correct XYZ. Debug mode previews without copying. Report saved to Desktop.

When to use it

Bringing a subset of content from a consultant's linked model into your own file (e.g. furniture or equipment layouts), migrating elements from an old linked model into the working model, or checking for overlap/duplication before committing to a full copy.

How to open it

Click "Copy From Link" on the I-TOOLS ribbon, Utilities panel. Opens a modal dialog (Revit is blocked until it's closed).

Features

  • Entry
    • Ribbon Button — Opens the modal Copy From Link dialog
  • Step 1
    • Link Dropdown — Chooses which loaded Revit link to copy elements from
    • No Links Warning — Warns when no Revit links are loaded
  • Step 2
    • Category List — Multi-select list of the linked model's categories to copy from
    • Select All Button — Selects every category in the list
    • Clear All Button — Deselects every category in the list
  • Step 3
    • Respect Crop/Section Box — Limits the copy to link elements whose bounding box falls inside the host active view's crop/section box (default on)
    • Skip Duplicate Elements — Skips elements whose bounding-box center is within ~10mm of any host-model element, regardless of category (default on)
    • Debug Mode — Runs the full scan/duplicate check and produces a report but copies nothing (default off)
  • Footer
    • Run Copy Button — Executes the copy (or the preview scan, in Debug mode)
  • Result
    • CSV/TXT Report — Saves a report of every candidate element's ID, Category, Family, Type and Status
    • Face-Hosted Family Handling — Face-hosted families (e.g. ceiling-mounted equipment) are re-placed as non-hosted at the correct XYZ position since their host face reference can't transfer between documents
