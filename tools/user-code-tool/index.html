User Code Tool

Releasedi-Tools for Revit

Open your personal C# script library: write, validate, run and save your own Revit scripts.

What it does

Write ordinary C# statements (no class, no project) with uiapp, uidoc, doc, activeView and selection ready to use, and Print(...) to the output console. Validate compiles without running; Run executes on Revit's API thread. Save scripts with a name, description, tooltip and PNG icon; duplicate, delete, search. Live output, execution history and a built-in guide with tested examples. Scripts are NOT sandboxed — they can change the model; use a Transaction to modify it.
