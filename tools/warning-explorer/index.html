Warning Explorer

Releasedi-Tools for Revit

Browse, isolate and clean every Revit warning in the active document.

What it does

Warning Explorer collects every warning Revit is currently tracking in the model, sorts them into a category tree (Geometry / Rooms / Structure / MEP / Annotation / Imports / Performance / Other), and lets you inspect, isolate, delete or automatically fix them. A second "Smart Fix" tab runs 13 built-in automated fixers with a before/after preview so you're never guessing what a fix will do.

Collects warnings, classifies them by category (Geometry / Rooms / Structure / MEP / Annotation / Imports / Performance), into a tree view. Per warning: Visualize (isolate in 3D), Navigate to element, Delete, or Smart Fix (auto-resolve via registered fixers).

When to use it

Before issuing a model for coordination or handover, to triage a noisy warnings list after a big edit, or to batch-clean recurring issues like overlapping lines/walls, duplicate marks, unenclosed rooms, or open MEP connectors.

How to open it

Click Cleanup & QA → Warning Explorer on the ribbon.

Features

  • Explorer tab
    • Warning Categories tree — Groups warnings by Geometry/Rooms/Structure/MEP/Annotation/Imports/Performance/Other
    • Search box — Filters the grid by description text
    • Live refresh — Keeps the warning list current as the model changes
    • Refresh (F5) — Manually re-collects warnings
    • Select clash elements — Selects the physical elements of checked (or all visible) warnings in Revit
    • Isolate in view — Temporarily isolates the warning's elements in the active view
    • Isolate (new 3D) — Creates a section-boxed 3D view around the elements
    • Remove checked — Deletes the elements tied to the checked warnings
  • Explorer tab row action
    • Select (▣) — Selects the physical element(s) of one warning row
    • View (👁) — Visualizes/overlays the warning's elements
    • Target (🎯) — Zooms and section-boxes to the element
    • Reset (↺) — Clears graphics overrides for that row
    • Delete (🗑) — Deletes the element(s) of that row
  • Smart Fix tab
    • Detect (Ctrl+F) — Re-scans warnings for fixable candidates
    • Select all / None — Ticks or clears every fix candidate
    • Apply checked (Ctrl+Enter) — Applies every ticked fixer
    • Settings (Ctrl+,) — Opens the fixer settings window
  • Smart Fix tab preview
    • Apply — Applies the single selected candidate's fix
    • Skip — Leaves the candidate unresolved for this session
    • Ignore permanently — Marks the candidate to never be offered again
  • Fixers
    • 13 built-in fixers — Auto-resolve specific warning types (overlaps duplicate marks off-axis lines unenclosed rooms duplicate sheet numbers cannot-keep-joined analytical inconsistency open connectors disconnected systems identical instances)
    • Analytical remodel-in-place — Rebuilds the analytical member from the physical element without touching the physical element
  • Settings window
    • Geometry tolerances (mm) — Sets endpoint/bbox tolerances for Lines Walls Floors Columns fixers
    • Off-axis straightening — Sets angle tolerance and an opt-out Comments keyword
    • Rooms / MEP — Sets room bridge gap and connector snap/size tolerances
    • Annotation — Sets discipline-prefix option for duplicate marks and sheet suffix scheme
    • Enabled fixers — Turns individual fixers on/off
    • Reset defaults / Save — Reverts or persists the settings
