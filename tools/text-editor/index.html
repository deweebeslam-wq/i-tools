Text Editor

Releasedi-Tools for Revit

Bulk find/replace, re-case and prefix/suffix editable annotation text.

What it does

Finds every piece of editable text in your model or current view — text note bodies plus editable string parameters on tags, generic annotations, detail items and title blocks — lists them all in one grid, and lets you bulk find/replace, change case, add prefixes/suffixes, clean whitespace, or write parameter-token patterns across all of them, staged for review before a single Apply writes everything in one transaction.

Scans the current view or the whole project and lists every editable text value — text notes plus editable instance string parameters on tags, generic annotations, detail items and title blocks — in one grid. Find & replace (case / whole-word / regex), convert case, add prefix/suffix, trim and clean, with an optional 'only apply where' filter. Every change is staged and previewed; Apply writes them in a single transaction so one Ctrl+Z undoes the whole batch. Read-only parameters are excluded automatically.

When to use it

- Standardizing text note capitalization across a whole project. - Stripping stray line breaks/double-spaces left over from copy-pasted text. - Batch-renaming tag text or title block fields with parameter tokens (e.g. "{Level}-{Mark}"). - Running conditional IF/THEN rules to fix specific patterns automatically.

How to open it

I-TOOLS tab → Annotation pulldown → Text Editor. Opens as a modeless window (singleton — reopening just brings the existing window forward).

Features

  • Title Bar
    • Scope dropdown — Chooses whether the scan covers the Current View or the Entire Project
    • Scan button — Runs the scan and populates the grid with every editable text value found
  • Find Replace
    • Find textbox — Text or regex pattern to search for
    • Replace textbox — Replacement text
    • Match case checkbox — Makes the find/replace case-sensitive
    • Whole word checkbox — Restricts matches to whole words only
    • Regex checkbox — Treats the Find text as a regular expression
    • Replace button — Runs the find/replace across in-scope rows' New Text
  • Case and Clean
    • Case dropdown — Chooses a case conversion mode: No change, UPPERCASE, lowercase, Title Case, Sentence case, PascalCase, camelCase, snake_case, SCREAMING_SNAKE, kebab-case
    • Apply case button — Applies the chosen case conversion to in-scope rows
    • Prefix textbox and +Pre button — Prepends the given text to every in-scope row's New Text
    • Suffix textbox and +Suf button — Appends the given text to every in-scope row's New Text
    • Trim button — Trims leading/trailing whitespace from in-scope rows
    • Collapse button — Collapses runs of 2+ spaces/tabs into a single space
    • No breaks button — Replaces line breaks with a space then collapses spaces
  • Token Pattern
    • Pattern textbox — Builds new text from parameter tokens like Level dash Mark
    • Token dropdown — Lists insertable tokens: Family, Type, Category, Level, Mark, Comments, View Name, Sheet Number, Sheet Name, Element ID, Date, Time, Username, Model Name
    • + token button — Inserts the selected token into the Pattern textbox
    • Apply pattern button — Expands the pattern per row using live Revit parameter values and writes the result to New Text
    • Live preview text — Shows the pattern expanded against the first in-scope row
  • Conditional Rules
    • Add rule button — Adds a new IF/THEN rule row to the rules grid
    • Run rules button — Runs all enabled rules top-to-bottom against every in-scope row's New Text
    • On checkbox — Enables or disables a rule without deleting it
    • IF field dropdown — Chooses which row token the rule condition tests: New Text, Current Text, Category, Field, View
    • Operator dropdown — Chooses the comparison operator: Equals, Not Equals, Contains, Does Not Contain, Starts With, Ends With, Greater Than, Less Than, Greater or Equal, Less or Equal, Is Empty, Is Not Empty, Regex Match
    • Value textbox — Comparison value for the condition (hidden/ignored for Is Empty/Is Not Empty)
    • THEN action dropdown — Chooses the transform to apply when the condition matches: Replace Value, Add Prefix, Add Suffix, Find and Replace, Convert Case, Copy From Field, Pattern Builder, Clear Value, Remove Prefix, Remove Suffix
    • Action value textbox — Parameter value for the chosen THEN action
    • Replace with textbox — Second parameter, used only by the Find and Replace action
    • Remove rule button — Deletes that rule row
  • Only Apply Where Filters
    • Match ALL checkbox — When checked, a row must satisfy every filter condition; unchecked, matching any one is enough
    • Add condition button — Adds a new filter condition row
    • NOT checkbox — Inverts a filter condition
    • Field dropdown — Chooses which row field the condition tests: Category, Field, View, Current Text
    • Operator dropdown — Chooses the comparison operator: equals, not equals, contains, doesn't contain, starts with, ends with, greater/less than, greater/less or equal, is empty, is not empty, regex
    • Value textbox — Comparison value for the filter condition
    • Remove condition button — Deletes that filter condition row
  • Grid Display Filter
    • Show textbox — Free-text filter that hides non-matching rows from the visible grid (display only)
    • Modified only checkbox — Shows only rows with a staged change
    • Apply to checked only checkbox — Restricts batch ops and Apply to only the rows whose row-checkbox is ticked
    • Check shown button — Ticks the checkbox on every row currently visible in the grid
    • Uncheck all button — Clears every row checkbox
    • Scope hint text — Live summary describing which rows the ops currently affect
  • Grid
    • Row checkbox — Includes this row when Apply to checked only is enabled
    • New Text column — Editable staged value for the row; colour-coded by status
  • Footer
    • Export CSV button — Saves the grid (Category/Field/View/Id/Current/New/Status) to a .csv file
    • Revert all button — Discards every staged edit, resetting New Text back to Current Text
    • Apply button — Writes every dirty row to the model in one transaction
