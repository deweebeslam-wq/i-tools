Activity Log

Releasedi-Tools for Revit

Browse everything every I-TOOLS tool has logged — on this PC and across the team.

What it does

One grid over every tool's log file. Filter by tool, machine, level, date range or free text; 'Problems only' narrows to warnings and errors. When central logging is enabled in Settings, the other machines' folders are read too, so you can see which workstation hit an issue and when. Export the filtered view to CSV. Read-only — it opens no transaction and needs no active document.
