Settings

Releasedi-Tools for Revit

I-TOOLS global settings — Manage Tools, Sync Reminder, central activity logging.

What it does

This is the one central place for plugin-wide preferences in I-TOOLS. Today it holds a single group of preferences — the Sync Reminder — which controls how and when the plugin nags you to Synchronize with Central on workshared models. As more plugin-wide preferences are added in the future they will appear here too.

Central settings window for plugin-wide preferences. Tools: choose which tools the ribbon shows and star favourites. Sync Reminder: enable/disable, reminder interval (15/30/45/60/90/120 min), snooze duration (5/10/15/30 min), and startup behaviour (auto-start, workshared-only, reset-after-sync, last-sync indicator). Activity Log: mirror every tool's log to a shared folder so each PC reports into its own sub-folder, with a machine/user stamp on every line, a retention window and a 'Test connection' probe.

When to use it

Use it when you want to turn the Sync Reminder popup on or off, change how often it appears, change how long "Remind Me Later" snoozes it for, or change what conditions trigger it (e.g. only on workshared models). Also useful any time you just want to check "how long has it been since my last sync" or trigger a sync immediately without leaving the settings window.

How to open it

Click the I-TOOLS ribbon tab → in the Settings panel, click the Settings button. The window opens modeless (non-blocking) — you can keep working in Revit while it's open. If it's already open, clicking the button again just brings the existing window to the front instead of opening a second copy.

Features

  • Live status strip
    • Last Sync readout — Shows minutes since last sync, colour-coded green (<20 min) / yellow (20-30 min) / red (>30 min)
    • Workshared status line — Shows whether the active model is workshared or not
    • Synchronize Now button — Immediately runs Synchronize with Central for the active document
  • Sync Reminder
    • Enable Sync Reminder checkbox — Master on/off switch for the whole reminder feature
    • Reminder interval dropdown — How long between reminder popups
    • Snooze duration dropdown — How long "Remind Me Later" defers the popup
  • Startup Behaviour
    • Start Sync Reminder automatically when Revit opens — Controls whether the timer auto-starts on Revit launch
    • Show reminder only for workshared models — Restricts popups to workshared (central/local) documents
    • Reset timer after every successful Synchronize with Central — Restarts the full interval countdown after any successful sync
    • Display 'Last Sync Time' indicator — Shows/hides the colour-coded last-synced readout on the popup
  • Footer
    • Cancel button — Discards changes made in the window
    • Save button — Persists all field values and applies them immediately
