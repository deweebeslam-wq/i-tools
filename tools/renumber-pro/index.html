Renumber Pro

Releasedi-Tools for Revit

Renumber elements into any writable parameter — view, project, window-sort or manual pick.

What it does

Renumber Pro writes a sequential (or lettered, or chainage-style) series of values into any writable Revit parameter — Mark, Comments, Type Mark, or a custom shared/project parameter — across a set of elements you choose. It replaces the old "select each element, retype the Mark" workflow with a live, editable preview and a one-click undo.

Reuses the I-TOOLS parameter framework to write Mark/Comments/any writable shared or project parameter. Modes: Active View, Entire Project, Window selection (L→R / R→L / T→B / B→T), and Manual pick order. Number settings: start, increment, prefix/suffix, zero-padding, letters (A,B,…AA), order (forward/reverse/random/continue-from-highest), skip-existing. A temporary-GUID pass plus a warning-swallowing failure handler prevent duplicate-mark warnings. Live preview + one-click session Undo.

When to use it

Renumbering columns/beams after adding or deleting some mid-run; numbering doors/windows left-to-right along a corridor; assigning sequential room or space numbers; renumbering viewport Detail Numbers on a sheet; giving structural elements a chainage number along an alignment (bridge piers, road structures); re-sequencing a schedule's Mark column to match the printed row order; fixing gaps or duplicates in an existing numbering scheme.

How to open it

Click I-TOOLS tab → Utilities panel → "Renumber Pro". The window opens modeless (stays open while you keep working in Revit) and is a singleton — reopening it just brings the same window forward.

Features

  • Elements
    • Mode dropdown — Chooses where elements come from: Active View, Entire Project, Window selection, Manual pick, Schedule, Path
    • Selected rows only — Restricts Schedule mode to rows currently selected
    • Direction dropdown — Spatial sort order: L-R R-L T-B B-T Serpentine Grid Radial
  • Category
    • Category search box — Filters the category dropdown list by typed text
    • Category dropdown — Chooses which element category to number
  • Write to
    • Parameter search box — Filters the destination parameter dropdown
    • Destination parameter dropdown — Chooses the writable parameter that receives generated values
    • Quick param buttons — One-click shortcuts to Mark, Type Mark, or Comments
  • Advanced - Numbering
    • Style dropdown — Numeric, Letters (A..AA), or Station (chainage)
    • Start textbox — First value in the numbering sequence
    • Step textbox — Increment applied between consecutive values
    • Pad textbox — Zero-pads numeric values to N digits
    • Prefix textbox — Fixed text placed before every generated value
    • Suffix textbox — Fixed text placed after every generated value
    • Order dropdown — Forward, Reverse, Random, or Continue From Highest
    • Skip already numbered (gap-fill) checkbox — Only numbers elements whose destination is currently blank
    • Skip existing values checkbox — Avoids reusing a value already present on another element
    • Preserve existing prefix checkbox — Keeps an element's current non-digit prefix and replaces only the trailing number
  • Advanced - Grouping
    • Restart numbering for each dropdown — Parameter whose distinct values restart the counter
    • Prefix with group checkbox — Prepends the group value to the generated number
    • Group separator textbox — Character(s) placed between group value and number
  • Advanced - Extras
    • Also copy number to dropdown — Optional second parameter that receives the same value
    • Export xlsx button — Exports the last run to an Excel file
    • Import xlsx button — Imports a spreadsheet's New-value column and applies it
    • Save preset button — Saves all current settings as a named JSON preset
    • Load preset button — Loads a previously saved preset
    • Open log button — Opens the diagnostics log folder
    • Undo history list — Lists every past Apply run with an Undo to here button
  • Review grid
    • Live preview checkbox — Auto-refreshes the preview grid on any setting change
    • Include checkbox (per row) — Excludes an element from the renumber while keeping it visible
    • Zoom button (per row) — Zooms/selects to that element in the active view
    • NEW column (editable) — Lets the user manually override a generated value
    • Drag-reorder rows — Changes the order used for numbering
    • Right-click context menu — Zoom to, Isolate, Select, or Copy new value for a row
  • Apply
    • Undo button — Reverts the most recent Apply run
    • Resequence button — Re-numbers 1-2-3.. down the current row order
    • Refresh button — Force-rebuilds the preview grid
    • Apply button — Commits preview values to the model
  • Help
    • Help button — Opens a plain-English usage guide
