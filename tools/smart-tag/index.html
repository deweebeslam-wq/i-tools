Smart Tag

Releasedi-Tools for Revit

Tag every element by category rules, avoiding clashes — then check and review the result.

What it does

Automatically places an IndependentTag on every visible element of one or more chosen categories in the active view, guaranteeing none of the new tags overlap each other or existing tags — like a "Tag All Not Tagged" that never produces a clash.

One tool for Tag All and Tag All No-Clash. Category rules (tag type + optional view filter / selection set) for the active view, selected elements, the views on a sheet or views picked in the Project Browser. Smart placement scores many candidate spots per tag against existing tags, text, dimensions, symbols, model linework and optional CAD / linked models, repairs the whole layout, then measures every created tag in Revit and re-places what collides. A results table reports clean / possible / clash / unplaceable per host, with Show, Next / Previous position, Reposition, Mirror, Flip, Validate again and Check active view. Fast mode for speed. One undo.

When to use it

- Tagging every door/window/structural column in a large plan without manually nudging overlapping tags. - Cleaning up a plan where existing tags overlap, by re-running with "Optimize existing tags." - Producing a consistent, hands-off tagged drawing set across many views.

How to open it

I-TOOLS tab → Annotation pulldown → Tag All No-Clash. Opens as a modeless (non-blocking) window — you can still click around the model while it's open.

Features

  • Categories Panel
    • Category checkbox list — Lists every category with a loaded tag family and untagged elements in the active view
    • Per-category tag type dropdown — Chooses which loaded tag family/type to use for that category
  • Options
    • Use Leader — Forces a leader line on every placed tag, not just displaced ones
    • Tidy layout (align + distribute) — Aligns tags into neat columns/rows with even spacing and parallel leaders
    • Vertical tag text — Rotates tag text 90 degrees instead of horizontal
    • Respect existing tags — Treats existing tags as hard obstacles new tags may never overlap
    • Optimize existing tags — Re-places existing tags of the selected type through the same scoring engine
    • Debug visualization — Draws detail lines showing chosen tag rectangles, leader paths, and X markers on unplaceable elements
    • Cell padding slider — Extra spacing (50%-200%) added around each tag's measured bounding box before searching for a free cell
    • Max search slider — How many spiral-search rings (2-20) to try before marking an element Skipped
  • Result Summary
    • Tagged count — Number of elements successfully tagged
    • Skipped count — Number of elements with no free cell found within Max search
    • Auto-leader forced count — Number of tags that got an automatic leader because they were displaced from their ideal position
    • Errors count — Number of placement failures
    • Show Skipped IDs button — Opens a message box listing the actual skipped element IDs
    • Show Warnings button — Opens a message box listing warning messages from the run
  • Footer
    • Tag All in View button — Runs the tagging placement across all ticked categories
    • Clear Tags of Type button — Deletes all tags of the currently ticked category/type(s) in the active view
