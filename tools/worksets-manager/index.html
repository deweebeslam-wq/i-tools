Worksets Manager

Releasedi-Tools for Revit

BIM-manager control centre for worksets — audit, batch create/rename, merge, standards, templates and reports.

What it does

Worksets Manager is a one-stop dashboard for managing worksets in a workshared (collaboration-enabled) Revit model — see every workset with live element counts, create/rename/merge them in bulk, move elements between them, audit for problems, and check the model against your firm's workset-naming standards.

Modeless dashboard for workshared models. View every workset with live element counts, open/closed + editable + owner status. Create single/batch/from-template, batch rename (find&replace / prefix / suffix / case) with preview, merge worksets (moves elements; the empty source remains — Revit has no delete-workset API), move the Revit selection onto a workset, audit (empty/near-empty/oversized/duplicate/CAD/non-standard), validate company standards, save/import/export JSON templates, and export CSV/Excel reports.

When to use it

Setting up worksets on a new workshared project from a saved template; cleaning up messy or duplicate workset names before a BIM coordination handover; auditing a model for empty, oversized, or non-standard worksets before an audit/QA review; consolidating several worksets into one; bulk-moving all elements of a category (e.g. all CAD imports, all a specific discipline's elements) onto the correct workset; validating a model against a documented naming standard before it's shared with a client.

How to open it

Click I-TOOLS tab → Utilities panel → "Worksets Manager". The tool requires the current model to be workshared — if it isn't, a message explains this and the tool does not open. Otherwise it opens as a modeless, tabbed window.

Features

  • Header
    • Refresh button — Re-scans every workset for a fresh element count and status
  • Dashboard
    • Stat cards — Read-only counts: Total, Empty, Unused, Open, Closed, Non-standard, Problematic, Linked
  • Worksets tab
    • Worksets grid — Lists every workset with checkbox, Name, Id, Elements, Status, Access, Owner
    • Target workset dropdown — Chooses the destination workset for Merge/Move actions
    • Merge selected to target button — Moves all elements from ticked worksets onto the target
    • Move Revit selection to target button — Moves the current Revit selection onto the target workset
    • Move by category - Scope dropdown — Chooses Active view or Entire project for category move
    • Move by category - Category dropdown — Chooses which category to bulk-move
    • Move whole category to target button — Moves every element of the picked category onto the target workset
    • Save selection as template button — Saves ticked worksets' names as a reusable template
    • Export CSV button — Exports a workset + issues report
    • Export Excel button — Exports a styled Excel workbook report
  • Create tab
    • Single name textbox + Create button — Creates one new workset by name
    • Batch textarea + Create all button — Creates many worksets from a newline/comma/semicolon list
    • From template dropdown + Apply template button — Creates every workset from a saved template that doesn't already exist
    • Export/Import template buttons — Saves or loads a template as a shareable .json file
  • Rename tab
    • Find/Replace textboxes — Literal text substitution across workset names
    • Prefix/Suffix textboxes — Text to prepend/append to workset names
    • Case dropdown — Case transform: UPPERCASE, lowercase, Title Case, Sentence case, PascalCase, camelCase, snake_case, SCREAMING_SNAKE, kebab-case, or No change
    • Selected only checkbox — Restricts rename to worksets ticked on the Worksets tab
    • Preview button — Computes Old to New name mapping without writing
    • Apply button — Writes the previewed renames to the model
  • Audit tab
    • Run audit button — Scans the workset snapshot for issues
  • Standards tab
    • Allowed prefixes textbox — Comma-separated list of approved workset name prefixes
    • Validate button — Runs pass/fail checks against the standard
    • Save standard button — Persists the current standard to disk
  • Linked models tab
    • Linked worksets list — Read-only list of every loaded link's own worksets
  • Footer
    • Open log button — Opens the diagnostics log folder
    • Copy last error button — Copies the last error message to the clipboard
