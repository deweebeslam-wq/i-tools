i-Civil2026-11-04

v1.9.0

i-CIVIL 1.9.0

Release notes

i-CIVIL by Mohamed Zeaiter

What's New

  • Automatic updates (new, i-CIVIL ▸ Updates): i-CIVIL now updates itself from GitHub, the same way I-TOOLS for Revit and Navisworks do. About 20 seconds after Civil 3D starts it checks for a new version (at most once a day) and shows what's new with Update Now or Later. Every download is checked against its SHA-256 before anything is installed. Civil 3D keeps the add-in files in use, so the i-CIVIL updater waits in its own small window and installs as soon as you close Civil 3D - and Navisworks too, if the i-CIVIL Navisworks plugin is installed. A failed or cancelled install leaves your current version untouched
  • Updates window (new, i-CIVIL ▸ Updates, or ICIVILUPDATES): see your version and when it last checked, Check for Updates now, choose Ask me before installing or Download automatically, install when I close Civil 3D, and opt in to beta versions
  • First release on GitHub: installers and release notes for every version are now on this page

Included tools

  • Importers: COGO points from CSV, TXT or Excel, Blocks to Points, LandXML, pipe networks from Excel or CSV, and profiles from station-elevation files
  • Pipes: Lines to Pipes, Structures from Points, Split Pipe, Set Pipe Cover, Swap Parts, Level Services, spreadsheet Pipe and Structure Editors, and Structure Reports to Excel
  • Navisworks: Find by Handle, Copy Handle, and Navis > Acad - send a Navisworks selection to Civil 3D as 3D blocks at exact coordinates
  • BIM Export: Navisworks NWC and IFC from one dialog
  • Sheet Export: one PDF per layout, a combined PDF and plain AutoCAD DWGs, in the background while you keep working
  • Smart Filter (SFILTER): a palette that finds objects by type and any mix of property rules, then selects, zooms to, isolates, hides or exports them

Install

  • Close Civil 3D, run iCIVIL-Setup-1.9.0.exe, and choose all users or just you. From here on i-CIVIL updates itself
  • Install this version by hand once, also if you have 1.8.0 or older: earlier versions cannot update themselves
  • Supports Civil 3D 2026. The optional Navisworks plugin supports Navisworks Manage and Simulate 2025
  • Windows may show a SmartScreen warning because the installer is not yet code-signed: More info → Run anyway

Works with Civil 3D 2026

i-Tools for Revit2026-10-27

v3.14.0

I-TOOLS 3.14.0

Release notes

What's New

  • CAD → HVAC (new, I-TOOLS MEP ▸ HVAC): turn the ductwork of a linked or imported DWG into Revit ducts and fittings. Double-line ducts become centre lines with their width, sizes are read from the drawing's labels (W×H, Ø, BOD / CL / TOD) or set per layer, elbows and transitions drawn in the plan are recognised, and every network is checked before anything is made - branches that are not square, ducts too short for their fittings, missing routing preferences, ducts that already exist. Choose rectangular or round duct types per layer or network, the system per service (missing Fresh Air and similar system types are copied for you), and Bottom / Centre / Top elevation reference. Review shows a plan at true duct widths and a 3D preview; Create builds ducts, elbows, tees, takeoffs, crosses, transitions and optional caps in one Undo, and a re-run never makes anything twice. Air terminals, equipment and dampers are listed in this version, not placed yet
  • User Code Tool (new, Automation ▸ Custom Scripts): write and run your own C# in Revit. Editor with completion, inputs you are asked for at run time, a helper library, a Results grid, snippets, a script library with icons, import / export, worked examples and an in-app guide. Scripts run on Revit's API thread; tick one option to make a whole run a single Undo step
  • MCP Connection Manager (new, Automation ▸ AI Connection): connect Claude Code, Claude Desktop or any MCP client to the Revit model you have open. About 140 tools: look at the model (elements, parameters, views, sheets, schedules, warnings, reports), run i-Tools engines (Model Health, Missing Tag Detector, Warning Explorer, Column Check, Weight Calculator, Template Manager and more), and - only if you allow it - change or model elements, each call one Undo step. Permissions per tool; a fresh install is Read Only, and edits can ask you to click Allow in Revit first. The AI Client Setup tab writes the client configuration for you and tests the connection
  • CAD → Structure - column modes and 3D preview: choose whether a plan's columns stand on its level (Same Level, as before) or come up from the level below (Level Below); walls follow the same rule. Levels are matched by elevation, never by name, and an ambiguous level is sent to review instead of guessed. New 3D preview of exactly what Create will build (orbit, pan, zoom, standard views, level planes, CAD lines), and checks before Create (no base level, zero height, missing types, elements far above / below the levels)

Improvements

  • Smart Tag: new Tag side option - put every tag of a run on the same side of its element (Right, Left, Above, Below or a diagonal; Auto keeps each category's usual spots). Each element's spot on that side is reserved until it is tagged, and tags line up per row or column of elements, so a whole view reads as one neat drawing
  • Weight Calculator: "Force one density for all targets" applies a single density to everything and records it. A missing density can no longer go unnoticed - Status is the second column in red, with counts in the header and footer and a list of the materials after Calculate
  • Grid Dimensions, Toggle Grid Bubbles, Smart Selection Sets, Clash Test Pro and Element Colorizer now share their engines with the MCP tools, so the ribbon button and the AI give the same result

Bug Fixes

  • CAD → Structure: a level within 250 mm of the drawing's level is now treated as the same storey instead of becoming the columns' base or top

v3.13.0

I-TOOLS 3.13.0

Release notes

What's New

  • CAD Blocks → Families (new, Modeling Tools): place families on the blocks of a linked or imported DWG. Lists every block (nested blocks and dynamic-block copies included), maps each block to a family type - tick and Apply, or auto-match by name - and places them: on a ceiling or floor (at a named reference plane or at a level + offset, optionally up to the ceiling above, face-based, ceiling-hosted or unhosted) or on a wall (at the nearest wall face, in this model or in a link, wall-hosted or unhosted). Mirrored blocks are mirrored, a dry run shows what would happen, one Undo reverses it all, and the mapping is remembered per DWG. Made by Ahmed Ramadan - thank you ❤️
  • Load Classification (new, I-TOOLS MEP ▸ Electrical): set the load classification of family power connectors in bulk. Lists every family with power connectors with its category, placed count and current class; tick families, assign a class, and the tool edits and reloads each family for you. Create new demand factors and load classifications from the same window. Made by Ahmed Ramadan - thank you ❤️
  • Missing Tag Detector (new, Annotation): scans the active view for visible elements that no tag in that view points to, lists them and marks them on screen without changing the model. Select all, zoom to an element, clear the highlight; linked models optional. Idea by Yamen ❤️
  • Align Tags (new, Documentation panel): pick a reference tag, pick the tags to move and finish. Split button with Automatic, Horizontal, Vertical and Left / Right / Top / Bottom edge modes, so tags of different lengths form a clean row or column. Idea by Yamen ❤️
  • Weight Calculator (new, I-TOOLS Structure ▸ Design Check): calculate the mass (kg, t) and weight force (kN) of the elements in a view, or of components nested inside families, from your own densities. Reads Revit's Volume AND measures the solids, compares both and flags differences for your review. Results are written only after you approve them, to shared parameters you set up; CSV export
  • Smart Tag (the former Tag All No-Clash, same button and shortcuts): one validated tagging tool - tags are checked after Revit commits them and re-placed if they clash. Leader angle 0-90° (default 45°) with an elbow, tags sit on their element where nothing else is, leaders never cross each other or run through another tag, and a Results window lists every host with Show, Next / Previous, Reposition, Mirror and Flip. Category rules can use view filters or selection sets
  • CAD → Piping, round 2: pipe sizes read from the drawing's labels, valves placed into their pipes (new built-in "I-TOOLS Inline Valve" family, or map your own), risers and fixture drops from circles on RISER / DROP layers, colour by service, a 3D preview, and revised drawings - pipes an earlier run made that the drawing no longer has are listed and can be removed

Improvements

  • Element Colorizer: categories and elements of linked models are listed and coloured (through view filters) - a structural model with MEP links now shows their pipes, ducts and fittings
  • Smart Tag: tags sit next to the symbol drawn in the plan (not the family's oversized bounding box), a tag next to its anchor gets a perfectly level leader, and elements outside the crop are skipped and reported
  • CAD → Piping: an elbow turning slightly over 90° is squared and sharper bends are cut into two elbows; tee straightening repeats until nothing moves; warning when two pipes meet at a riser at the same height; DXF labels are read directly
  • CAD → Piping drawing guide updated for labels, valves, risers and revised drawings

Bug Fixes

  • CAD → Piping: valves drawn on a pipe that runs straight through them are now found, and a valve next to a fitting slides along its pipe to fit
  • CAD → Piping: elbow and tee fittings that Revit refused on a real drawing (angle slightly over 90°, tee 0.2° off) are now built

v3.10.0

I-TOOLS 3.10.0

Release notes

What's New

  • New "I-TOOLS MEP" ribbon tab with a Piping panel (CAD → Piping, Pipe Splitter) and a new MEP category in the Tool Filter
  • CAD → Piping (new, I-TOOLS MEP ▸ Piping): turn pipe layouts drawn in CAD (imported or linked DWG / DXF) into connected native Revit pipes and fittings. Reads single- and double-line pipes (the width of a double line is the pipe's outer diameter), joins the gaps that Revit-exported drawings leave at fitting and valve symbols, never connects pipes that only cross, and recognises elbows, tees, crosses and reducers. Each connected network gets its own system type, pipe type and height (buried and high-level runs in one drawing). Gravity drainage: a fall % per layer or per network, the outlet marked on the plan and every pipe's elevation at both ends listed in Review. Before anything is built it checks the pipe type's routing preferences for every fitting and size; then it creates the pipes and fittings - one Undo, a list of every joint Revit refused with the reason, and nothing is created twice when you run it again
  • Pipe Splitter (new, I-TOOLS MEP ▸ Piping): split pipes by level (including levels of linked models), at a distance, at a spacing, at manual positions, or where they pass through picked walls and floors (in this model or in a link) - with unions or direct joins, keep / delete any piece, or move unwanted pieces to a workset. Live preview with a strip view of every pipe and per-piece ticks, a confirmation, a report and CSV export. Parameters, systems, insulation and connections are kept, and the original element always survives
  • Data Manager - new formula editor: type formulas like in Excel in one highlighted box, with autocomplete for parameters and functions and a live preview table. Supports {Name} / [Name] references, ^, comparisons and functions; checks the target type (Integer, Yes/No, Number) before Stage and warns about mixed units
  • CAD → Structure - hollow-block (ribbed) slabs: hollow-block slabs (layers H.Bl, HB, HOLLOW, RIBBED...) are built one-way or two-way, with the rib direction read from the drawing (RIBDIR / RIBLINE lines) or chosen per panel in the Preview, as one floor per panel (Lightweight) or topping slab + rib beams (Detailed). New "Drawing guide..." exports how the DWG must be drawn for the active profile
  • Manage Tools - show / hide ribbon tabs: Settings ▸ Tools ▸ "Ribbon tabs" turns the I-TOOLS Structure and I-TOOLS MEP tabs on or off; the choice is remembered

Improvements

  • TagAll: much cleaner layouts - tags sit beside their element (never on it), never clash, tidy into straight-leader rows and columns, and stay stable at any spacing. Pipes, ducts and other runs are tagged beside the run; a second tag stacks against the element's existing tag; rooms, spaces and areas use their own tag types
  • TagAll: elements hidden by view filters, hidden categories or the view template are no longer tagged (no more leaders to empty paper) and no longer push other tags away
  • CAD → Structure: beams drawn only on EDGE layers are now proposed; solid slabs no longer reuse hollow-block floor types; a view-specific import uses its own plan's level
  • CAD → Structure and CAD → Piping now read CAD through one shared reader
  • CAD → Piping: a reducer next to a tee becomes a reducing tee; layers with a size in the name are always single-line
  • Batch Export (Sheet + Shared Coordinates): AutoCAD is tested before the first sheet, with automatic fallbacks (own profile → your profile → older AutoCAD), one clear reason per sheet if none works, and a new "Test AutoCAD on this PC" button in Settings

Bug Fixes

  • Batch Export (Sheet + Shared Coordinates): fixed failures on PCs with a locked AutoCAD configuration, and "path too long" errors with deep export folders in Revit 2024
  • CAD → Structure: legend words spelled CONTINOUS / TRIMNTED / PLANTEDD are recognised; a block holding a whole plan is no longer taken as one footing

i-Tools for Revit2026-09-27

v3.4.0

I-TOOLS 3.4.0

Release notes

Improvements

  • Copy From Link no longer freezes Revit - its window is now modeless and opens quickly on large links
  • Tools that remember a list of elements (Renumber Pro, Sheet Organizer, Text Editor, Worksets Manager, Parameters Add, Smart Type Splitter, Family Manager, Data Manager) now refuse to apply to a different open project, so switching projects can never edit the wrong model
  • MEP Opening Generator: much faster detection on large models (about 80 s was spent in one scan), and buttons no longer need a second click after placing
  • Coordinate Manager: "Fixed digits in Revit" option, dry run really changes nothing, one Undo per run, progress window with Cancel
  • Data Manager: cleaner formula and bottom-bar layout

Bug Fixes

  • MEP Opening Generator: valid openings were flagged as orphans; linked elements could get comments written onto unrelated host elements; Update Opening could tilt wall openings about 90 degrees
  • Renumber Pro: no more false "updated" counts; exact schedule order; one number per row in non-itemized schedules; Undo per project
  • Copy From Link: doors/windows keep their hosts; face-based families detected correctly; failures reported
  • Join/Unjoin: "Selection" with nothing selected no longer processes the whole model; join orders no longer flip
  • Smart Sectioner: searches from non-3D views failed; section boxes on rotated links; colour overrides cleared
  • Sheet Organizer: swapping/shifting sheets failed because of a forbidden temporary character
  • Element Coder and Door Lintel: wrong level when the project base point is not at 0
  • Data Manager and Parameters Add: numbers written in the right units (1400 mm could become 1400 ft); conflicting type values are reported instead of the last row winning
  • TagAll and Toggle Grid Bubble: a second job was silently dropped
  • FileDiff: noise categories were never filtered on newer Revit
  • Clash Test Pro / FileDiff: window now follows the active project
  • Smart Clash Manager: Excel export with no rows lost its styling
  • Model Health Analyzer: wall type check included non-wall types
  • Align View To Face, Sheet Generator, Sheet Organizer, Move To Reference: a failed change is now reported instead of shown as success
  • Element Colorizer, Smart Type Generator, Sync Reminder, Smart Level Generator, Transfer From Project: smaller unit and reliability fixes

Also includes everything from 3.3.0 (Batch Exporter "Sheet + Shared Coordinates", Room Management guided workflow, ribbon logo).

v3.3.0

I-TOOLS 3.3.0

Release notes

What's New

  • Batch Exporter: new DWG Export Mode "Sheet + Shared Coordinates" (DWG Settings > Export Mode). Each coordinated plan is exported in shared coordinates and XREF'd into its sheet DWG with a matching viewport, then checked automatically (needs AutoCAD installed). Standard DWG export is unchanged and stays the default
  • Room Management: a guided six-step path on the Dashboard (Load > Detect > Name > Finishes > Check > Export), and every main page now says what to do next and why a button is greyed out
  • The I-TOOLS logo now appears on the ribbon tab

Improvements

  • Batch Exporter: DWG/DXF setups show only the settings that actually apply
  • Room Management: warns when skirting on a curved (spline) wall is approximated

Bug Fixes

  • Batch Exporter: image Zoom % was ignored
  • Batch Exporter: image file names now follow the naming pattern
  • Batch Exporter: an old file left from a previous run is no longer counted as a successful NWC/image export; combined PDFs are now checked too
  • Batch Exporter: "Open folder after export" now also opens DXF and FBX folders
  • Room Management: a rounding step of 0 no longer breaks the Finish Takeoff grid
  • Revit 2026/2027: Uniformat/Omniclass values are read correctly (those parameters changed in Revit 2026)

v3.2.0

I-TOOLS 3.2.0

Release notes

What's New

  • Automatic updates: I-TOOLS now checks GitHub once a day and offers new versions with release notes
  • Update Now downloads, verifies (SHA-256) and installs in the background - Revit can stay open; restart Revit to load the new version
  • Settings > Updates: turn automatic checks on/off, choose how often, opt in to beta versions, or check now
  • BCF 2.1 export in Smart Clash Manager and Clash Test Pro - one topic per clash with camera, selected elements, status, assignee and comments; re-importing updates topics instead of duplicating them

Improvements

  • About window now shows the real installed version
  • Keeps the previous version on disk so an update can be rolled back

Bug Fixes

  • Smart Clash Manager: Navisworks XML reports no longer lose clash points and element IDs after an image
  • Installer no longer removes files from under a Revit session that is still running the previous version

First time? Install I-TOOLS_Setup_v3.2.0.exe once by hand. From this version on, I-TOOLS updates itself.
